# Replay: round-2 counts

Run from the repo root, `ulimit -v 6000000`; every command under `timeout 1800` or less, serially (or at most two processes). All Python commands are `uv run --offline --no-project python -B`. Sources in `scripts/`; compile `z80_parity_{hj,huge,prime,composite,word,hii}.c` with `cc -O3 -lm` (put `-lm` after the source), producing temporary binaries. For `strict` add `-DSTRICT_ONLY` when compiling the prime engine. Redirections below use files in this data directory. Remove binaries after use. Main input list: `z80_jugular_inputs.py`; split by the exact prime sieve in `z80_square_span.py` to obtain `prime.txt` and `comp.txt`. `high.txt` consists of the 12 old R8 controls, the 1.59T control, and 2521 for overlap.

```
hj <inputs.txt >hj.csv
huge <high.txt >high5.csv
sort -nu inputs.txt high.txt | word >words.csv
prime -f prime.txt >prime.csv
strict -f comp.txt >strict.csv
composite 4 17401609 <comp-part.txt >part.csv   # split comp.txt into chunks of 10 or fewer rows; concatenate in order into comp.csv
hii <high.txt >highII.csv
composite 8 241 <small8.txt >small8.csv
```

Each raw row begins with n followed by **exact integer sums**; no rounding or inference from congruences. `hj.csv`: length 3 then 5, bad then good (Jacobi of HJ denominator +1/−1), ordered then up to reversal (lex-first representative), six weights per group: 1, Jacobi(first letter/n), (−1)^first, χ₋₄(middle), sign(word versus reverse in lex order), Jacobi(middle/n). `high5.csv`: only the length-five block. `words.csv`: six objects in order R, Rodd, R8, U7, HJ3bad, HJ3good; same ordered/unordered and six weights (comparison is between endpoints). U7 here counts *words*: ordered requires 8|tu for first outer u, unordered requires some valid orientation and uses the smaller outer letter for the weights. The R objects include all positive words, the HJ objects only canonical interior ones.

`prime.csv`, `comp.csv`, `small8.csv`: four groups indexed by the exact number k=0,1,2,3 of n-multiple denominators. For each group: unordered then ordered, each weighted by 1, Jacobi(first denominator/n), (−1)^first, χ₋₄(first), sign(last−first); unordered means sorted. Full counts sum all four bins. At composites this binning alone is **not** a strict I/II split. `strict.csv`: same layout for k=1,2 with every nonmultiple denominator a unit mod n; do not sum these for full ES at composites. `highII.csv`: only the strict II group, ten weights in the same order, not an unrestricted count. Jacobi sums at composite n include zero. `small8.txt` contains 131 and 241. `z80_parity_composite.c` is adapted from `z52b_fingerprint_count.c` and `z80_parity_prime.c` from `z52d_p2_ZF1_fastU.c`; all-odd duplicate-denominator corrections in the latter concern prime inputs ≥5, or our 1 mod 4 strict-composite controls. Memory plans: SPF int array of length 3n_max+11 for composite direct search; segmented gcd-free divisor lists of length O(√n) for word and high-II; constant working memory for the ordinary HJ scan. High record rows deliberately use 128-bit ES denominators.

For the length-5 high engine write the word [a,b,t,d,e], A=ab−1, C=de−1, so n=tAC−aC−eA. Orient A≤C (tie via endpoints). Since a/A,e/C≤2/3, AC≤3n/2. For M=tA−a≤K=floor(√n)/4+O(1), enumerate e|n+M from n+M=e(Md−A). Otherwise C≡−bn mod A, C≤min(3n/(2A),2n/K) by n/C=M−eA/C≥M−2A/3≥M/2. In this branch e is the unique residue −(n+aC)/A mod C in [2,C−1]. All divisions and HJ tests are exact (coarse square-root loop bounds have a guard). This reconstructs both orientations and then uses lexicographic order for unordered weights. In the high Type II scan, 2abd≤n and ce≤2b imply 4acde≤2(n+e). For e≤B=⌊√n⌋+1 factor (n+e)/4 by an interval sieve; for e>B, enumerate acd≤n/(2B)+1/2 and recover b=(nc+a)/(4acd−1). These are disjoint. Small overlap 2521 is checked against both other engines. `prime` and `strict` use the three-role decomposition documented atop `z52d_p2_ZF1_fastU.c`; strict-composite solutions have the same primitive representation as long as the nonmultiple entries are units (split the gcd of the like-type denominators). `comp` directly factors the reduced two-term remainder so that neither existence nor completeness of full counts at composites depends on ET. For HJ3 on the low panel, unweighted and signed columns also have the independent endpoint-divisor check in `words.csv`.

`z80_parity_audit.py` writes `residues.tsv`, `class.tsv` and stdout `audit.txt`. Residue masks have bit r set if an actual input has value r mod m. `class.tsv` reports whether the output is even determined by h(−4p) mod 32, not a significance test; for these primes H(4p)=h(−4p), −p is not an order discriminant, and r₃(p)=12h(−4p). The augmented matrix in `audit.txt` has columns I,II,Rodd,R8,U7,HJ3good,HJ3bad,HJ5good,HJ5bad,h(−4p)/4,1 (unordered counts). Scope: not an exhaustive search over possible trace identities. `z80_capzero_packet.py` prints `packet.txt`.
