                    An improved bound for the exceptional set
                         of the Erdős–Straus equation
                 Sushaan Kandukoori               Shrikrishna Ramesh                Pranava Kumar

                                                   July 29, 2026


                                                       Abstract
         Let E(N ) be the number of integers 2 ≤ n ≤ N for which
                                                   4  1 1 1
                                                     = + +
                                                   n  x y z

      has no solution in positive integers. Vaughan proved E(N ) ≪ N exp{−c(log N )2/3 }. We prove

                                          E(N ) ≪ N exp{−c(log N )3/4 }.

      For each a ≥ 1, the divisors of a2 supply congruence classes modulo 4a − 1 on which such representations
      exist. For a large parameter X, we select a family whose reciprocal moduli sum to order (log X)3 . Averaging
      over small divisors retains this weight while controlling shared prime factors. A finite counting argument
      gives the stated bound at the scale log X ≍ (log N )1/4 . The same argument gives this exponent for every
      fixed numerator m ≥ 4.

Keywords. Erdős–Straus conjecture, Egyptian fractions, exceptional sets, sieve methods, Bombieri–Vinogradov
theorem.


1   Introduction and main theorem
The Erdős–Straus conjecture asserts that for every integer n ≥ 2 the equation
                                                  4  1 1 1
                                                    = + +                                                            (1)
                                                  n  x y z
has a solution in positive integers. Let E(N ) count the exceptions 2 ≤ n ≤ N . Vaughan proved the classical
estimate
                                        E(N ) ≪ N exp{−c(log N )2/3 }
for some absolute c > 0 [15, p. 193, (2)]. Our main result improves the exponent.

Theorem 1 (main theorem). There is an absolute constant c > 0 such that, for all N ≥ 3,
                                         E(N ) ≪ N exp{−c(log N )3/4 }.

   The same saving holds relative to the primes: the number of exceptional primes up to N is ≪ π(N )
exp{−c(log N )3/4 } after decreasing c.
   For m ≥ 4, let Em (N ) count the positive integers n ≤ N for which m/n is not a sum of three unit fractions.

divisors supplies log z, which combines with the rough cofactor sum log X/ log z to give the third logarithm.
    Vaughan’s sieve estimates [16, Cor. 3.1.1] and Elsholtz’s treatment of sums of k unit fractions [5, Thm. 1.3 and

residue classes. Elsholtz and Tao proved bounds for the average number of representations over primes [7], and
Elsholtz–Planitzer give further results on the number of representations [6]; Bloom–Elsholtz survey Egyptian
fractions [2]. Bright and Loughran studied the associated surfaces through the Brauer–Manin obstruction [4].

divisibility and compare it with Type I/II descriptions.
Remark 1.2 (the exponent 3/4). For a family of congruences with total weight µ ≍ (log X)k and the overlap
estimates below, the level condition of Theorem 5.4 has the form log P (z) + O(µ log X) ≤ log N . When
log P (z) = O((log X)k+1 ), choosing log X of order (log N )1/(k+1) gives a saving exp{−c(log N )k/(k+1) }.
The family with prime moduli used in the Vaughan method has quadratic mass; see Pomerance–Weingartner [14,
Lemma 4.1]. Here the cubic mass gives 3/4.

Pomerance–Weingartner [14, Prop. 2.3 and Cor. 2.4]. The proof of Theorem 1 uses only Lemma 2.3.

7     Further remarks
Remark 7.1 (geometry). For numerator 4, the surface Un : 4xyz = n(xy + xz + yz) is an affine part of a Cayley
cubic; see [4]. In projective coordinates (x0 : x1 : x2 : x3 ), its closure is
                                    4x1 x2 x3 = nx0 (x1 x2 + x1 x3 + x2 x3 ).
Fixing x = an gives (4a − 1)yz = an(y + z), so the projective closures of these curves are the conic components
of explicit plane sections. On the plane x1 = anx0 , the cubic factors as
                                                                        
                                  nx0 (4a − 1)x2 x3 − anx0 (x2 + x3 ) = 0.
The factor x0 gives the boundary line x0 = x1 = 0.
Remark 7.2 (effectivity). The thresholds obtained here inherit the ineffectivity of the usual Bombieri–Vinogradov
theorem. Johnston [10] gives effective variants for sifting problems; applying them to this family requires a
separate analysis.
