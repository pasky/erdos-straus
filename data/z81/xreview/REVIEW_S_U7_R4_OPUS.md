1. **§0 Review line (form, required).** It lists only reviews R1–R3 of Round 1, which reads as though §§6–9 were reviewed. Add: "Round 2 (§§6–9): cross-model `REVIEW_S_U7_R4_OPUS.md` (or cross-review owed)."
2. **§0 Triage.** "BARRIER-BROAD (§§4,6)" mislabels the main new content. That content is an *anti*-barrier: unrestricted real menus have no exponent-4 ceiling. Suggested split:
   - BARRIER-SCOPED (or BARRIER-BROAD) for "every ring-class menu has 2-group abelianization", plus the ≤4 bound with a common p;
   - METHOD-CX for the 2ʳ sharpness (it kills the expectation of a 4-ceiling).

3. **Theorem C(3) understates the barrier.** Since Gᵃᵇ is a 2-group, detecting −1 mod 4C on all unramified primes needs (ℤ/4C)^× to be a 2-group. That means the odd part of C is a squarefree product of Fermat primes. "Not mod 7 or mod 9" is just the first instance; state the general condition, keeping the existing caveat that, for example, ℚ(ζ₁₇) is not shown to be available.
4. **Minor generalisation and precision in §6.**
   - ℓ≡1 mod 2N is needed only for the sign of the norm. For a B that is not totally real, norms are positive, so ℓ≡1 mod N suffices. The construction also works there if torsion ratios are put in the list.
   - "Totally real" in (1) is therefore a sufficient case, not a necessary one. Either say so or leave it, but do not imply it is needed.
5. **§9 calibration (substantive wording).** The model mean is dominated by tiny heights:
   - about 0.25–0.31 of it comes from p≤100 (five primes), and about 0.42–0.53 from p≤3000, where there are no actual exceptions;

   - my fixed-F test shows the local model is well calibrated, so the gap must come from large f near p (the archimedean range r|p+1), from correlations, or from chance.

   Report the split by height and the fixed-F calibration. Do not lean on "(0.599, 1.435) vs five". For reference only, not as a significance claim: P(≥5 | Poisson 1.435) ≈ 0.016 and P(≥5 | 1.01) ≈ 0.004.

   - Save the 10⁶ cross-check of `tail` vs `haar` to a data file. Neither code ever prints an intermediate B=10⁶, because its block grid skips it, so the note's "short checks agree" is not recorded.
