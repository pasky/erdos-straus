# Round 2 finite forecast design (before running)

**Assessment.** Use the same rough-composite population, height bins, hard residues, stratified blocks and prime-intensity normalization as the Round 1 pair engine. Use complete finite exponent boxes (centre formal, side fully factored), never equate `3^omega >= phi(k)` with a hit. Mark a failed window by phase 0/1 according as `3^omega(side) < phi(k)` or not, the threshold suggested by W (finite marker, *not* a theorem about these short windows, particularly composite k). Link consecutive disjoint pairs: maintain masses in the two phases of the last missed window. For the next pair, transport these by the composite-only joint both-miss and phase transition fractions, conditional on the previous pair having missed and its last phase. Use singleton first-miss fractions for incomplete updates. Include only controls that are units at each level used in the conditional frequency. Initial pair as in Round 1. If a positively weighted conditioning cell is empty, back off to the previous unmarked pair misses, then to the marginal pair if needed, and report uses. Ablations: unlinked marginal pairs and linked pairs without a phase mark. No calibration on prime gaps or records; use fixed disjoint pairs starting at 3 as before, not a selected rotation/depth. No model averaging or further variant if the prediction is poor. Outputs for the 18878-prime bulk and accumulated counts since 10^6 at the high record endpoints. This is an out-of-population comparison, not a blind benchmark.
