(b) A. Bhargava, "An approximate version of Vu's theorem on economical bases", arXiv:2609.27823, §1 (https://arxiv.org/pdf/2609.27823):
"Vu's Theorem states that for a given integer k ≥ 2, there exists s1(k) such that if s ≥ s1(k) then there exists X ⊆ N such that for all sufficiently large N one has |{(x1,...,xs) ∈ X^s : x1^k + ··· + xs^k = N}| ≍ log(N)." ... "The first is a polynomial concentration lemma due to Vu [22]" [= Vu, On the concentration of multivariate polynomials with small expectation, RSA 16 (2000)].
(c) C. Táfula, "On Vu's restricted box estimate in Waring's problem", arXiv:2605.15067v1, §1: "Vu [5] proved that, for s sufficiently large in terms of k, there exists A ⊆ {n^k} such that the number of representations of N as a sum of s elements of A is ≍ log N. The main number-theoretic input in Vu's argument is a restricted version of Waring's problem ... inside an arbitrary box."
Mechanism: random subset of k-th powers (inclusion prob. tuned so E R_s ≍ log N) + circle-method box estimate for expectation + polynomial concentration (Kim–Vu/Vu) + Borel–Cantelli.
