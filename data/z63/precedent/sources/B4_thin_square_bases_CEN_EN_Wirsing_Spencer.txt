(A) M. B. Nathanson, "Thin bases in additive number theory", Astérisque 147–148 (1987) 315–317. URL https://www.numdam.org/article/AST_1987__147-148__315_0.pdf . Status: V (survey by a coauthor, stating the theorems).
"THEOREM (Choi-Erdős-Nathanson [2]). For every n > 1 there exists a finite set A of squares such that A is a basis of order 4 for n and |A| < c n^{1/3} log n where c = 4/log 2. This is proved by means of an explicit construction."
"THEOREM (Erdős-Nathanson [3]). For every ε > 0 there exists a set B of squares such that (i) B is a basis of order 4, (ii) If n ≠ 4^r(8k+7), then n ∈ 3B, (iii) B(x) ~ c x^{(1/3)+ε} for some c > 0 as x → ∞. The proof uses the probability method of Erdős and Rényi. The Theorem is best possible except for the ε in the exponent in (iii)."
"THEOREM (Zöllner [8]). Let h ≥ 4. For every ε > 0 there exists a set B of squares such that B is a basis of order h and B(x) < x^{(1/h)+ε} for all x > x0."
"THEOREM (Wirsing [6]). Let h ≥ 4. There exists a set B of squares such that B is a basis of order h and B(x) < c(x log x)^{1/h} for some constant c = c(h) > 0 and all x > x0. Both Wirsing and Zöllner use probability methods to obtain their results, and, consequently, it is not yet possible to describe explicitly a sparse sequence of squares that is a basis of order 4."
"THEOREM (Wirsing [6]). For h ≥ 3, there is a set P of primes such that (i) n ∈ hP for all n > n0 such that n ≡ h (mod 2), (ii) P(x) < c(x log x)^{1/h} for some constant c > 0 and all x > x0."

"Using a probabilistic method, Erdős and Nathanson [3] showed that for every ε > 0 there exists a set A of squares such that (i) every nonnegative integer is the sum of four squares in A, (ii) if n ≠ 4^r(8k+7), then n is the sum of three squares in A; and (iii) A(x) ~ c2 x^{(1/3)+ε}. They also proved that for ε > 0 there exists a set A of numbers of the form p and pq, where p and q are primes, such that (i) every sufficiently large even integer is the sum of two numbers in A, and (ii) A(x) ~ c3 x^{(1/2)+ε}."
