ITEM 7 — Erdős–Turán conjecture status.
(a) Jain–Pham–Sawhney–Zakharov, CPC 34 (2025) 815, p.815 (see B3 file): "It is a major open problem whether there exists an additive basis of order 2 for which the factor of log N in the denominator can be replaced by an absolute constant; Erdős and Turán [6] famously conjectured that this is impossible." Status V.
(b) T. F. Bloom, Erdős Problem #28, https://www.erdosproblems.com/28 (page last edited 06 Apr 2026; LaTeX source https://www.erdosproblems.com/latex/28): "$500 If A ⊆ N is such that A+A contains all but finitely many integers then limsup 1_A∗1_A(n) = ∞. Conjectured by Erdős and Turán. They also suggest the stronger conjecture that limsup 1_A∗1_A(n)/log n > 0." Status V (statement); open status per (a).
(c) Erdős 1954 (B1b file): "TURÁN and I conjectured that if f(n) > 0 for all n > n0 then lim sup f(n) = ∞; this conjecture seems very hard to prove."

ITEM 8 — natural sets with polylog expected representation count, pointwise.
(a) JPSZ 2025 p.816 (V): "if one takes A to be the set of squares, then A + A contains all primes which are 1 mod 4 and by the divisor bound A + A has multiplicities bounded by N^{o(1)}. Therefore, if one is willing to assume strong number-theoretic conjectures, one can take A to be the set of numbers n which are within O((log n)^{O(1)}) a square. The purpose of this note is to present an explicit construction unconditionally." => the natural 'near-squares' set with polylog r(n) is only CONDITIONAL.
