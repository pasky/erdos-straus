SOURCE: P. Erdős, "On a problem of Sidon in additive number theory", Acta Sci. Math. (Szeged) 15 (1954) 255–259. URL https://www.renyi.hu/~p_erdos/1954-04.pdf (OCR via Jina reader; OCR noisy). Status: V.
"Denote by f(n) the number of solutions of n = a_i + a_j. About twenty years ago, SIDON raised the question whether there exists a sequence a_i satisfying f(n) > 0 for all n > 1 and lim f(n)/n^ε = 0 for all ε > 0. In the present note, I will construct such a sequence. In fact, my sequence will satisfy (1) 0 < f(n) < c1 log n for all n > 1. ... It seems probable that (1) can not be strengthened very much. TURÁN and I conjectured that if f(n) > 0 for all n > n0 then lim sup f(n) = ∞; this conjecture seems very hard to prove."
"We will not be able to construct our sequences explicitely, but we will be able to show that in some sense almost all sequences satisfy (1). ... Define A_k as the least integer greater than c2 k^{1/2} 2^{k/2}. Pick in all possible ways A_k integers from the interval (2^k, 2^{k+1}) ... if for each k one neglects o(binom) 'bad' choices ... the sequence ... will satisfy (1)." [counting/union-bound over random block choices]
NOTE: 1954 paper gives 0 < f(n) < c1 log n; the two-sided c1 log n ≤ f(n) ≤ c2 log n is attributed to Erdős (1956) in Alon–Spencer Thm 8.6.2 (see B1_B2 file).
