(A) J. Cilleruelo, "Sidon basis", arXiv:1304.5351v2 (24 Apr 2013) [publ. version: "On Sidon sets and asymptotic bases", Proc. LMS 111 (2015)]. URL https://arxiv.org/pdf/1304.5351 . Status: V.
"Conjecture 1.1. There is a Sidon basis of order 3." "Theorem 1.1. For all N large enough, the cyclic group Z_N contains a Sidon set S ⊂ Z_N which is a basis of order 3 in Z_N." (uses Granville–Shparlinski–Zaharescu equidistribution on curves over F_p)
"Theorem 1.2. There exists a B2[2] sequence of positive integers which is an asymptotic basis of order 3."
"Theorem 1.3. For any ε > 0 there exists a Sidon basis of order 3 + ε ... n = a1 + a2 + a3 + a4, a_i ∈ A, a4 ≤ n^ε."
"To prove Theorems 1.2 and 1.3 we will use the probabilistic method invented by Erdős and Renyi ... P(x ∈ A) = x^{−γ}." "Erdős and Tetali [13] proved that if γ < 1 − 1/h, then almost all sequences are asymptotic basis of order h. Thus, for any γ in (3/4, 4/5) ... almost all sequences in S(γ) are simultaneously Sidon sequences and asymptotic basis of order 5. This is the argument used in [20] [Kiss]." "In order to get basis of order 3 + ε we need to take γ close to 2/3 ... alteration method or deletion technique". Tools: vectorial sunflower lemma, modular Sidon basis.
"1.1. Note added on April 23, 2013. Kiss, Rozgonyi and Sándor [21] have proved the existence of a Sidon sequence which is an asymptotic basis of order 4."
