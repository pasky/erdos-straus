# z60 MS105 data
* `zeros105_1e10.txt` — the 38 non-square R-zeros n ≡ 1 (4), gcd(n,105) = 1, n ≤ 10^10 (from z58 LOGIC), with kernel.
* `sm2/`, `sm2big/` — kernel census n = s·m² < 2^64, kernels ≤ 10^5.  `win/` — windows to 10^37.  `nsq/` — m² + c.
* `pseudo/`, `locsq/` — pseudosquares and random locally-square inputs.
* `prim_2e7.txt` — `scripts/z60_ms105_prim.c 20000000`: primitive (gcd(u,B) = 1) vs inherited solutions, n ≤ 2·10^7.
