## 1. Reformulations used (PROVED, elementary)

**R1 (mutual divisibility).** For n odd and k, r ≥ 1 with gcd(r, k) = 1: if r | n + k, k | n + r and (n + r)/k ≡ 7 (mod 8),
then U₇(n) (word (x, y, z) = (r, (f+1)/r, k), f = (n + r)/k). Conversely every word gives r = x, k = z with x | n + z,
z | n + x and (n + x)/z = xy − 1 ≡ 7 (8), but **not** necessarily gcd(x, z) = 1 (n = 63: word (6, 4, 3)). For a prime
p > 3 coprimality is automatic: g = gcd(x, z) divides n + z and z, so g | p; g = p would give p² y − 2p ≤ p, impossible
for p > 3. *Proof (forward direction).* f := (n+r)/k is an integer ≡ 7 (8); k(f + 1) = n + r + k ≡ 0 (mod r) and gcd(r, k) = 1 give
r | f + 1; then xyz − x − z = (f+1)k − r − k = fk − r = n. ∎

**R2 (trivial classes).** U₇(n) for n ≡ 3 (mod 4) (Z60 Lemma 7(iii)) and for n ≡ 5 (mod 8): f = n + 2 ≡ 7 (8),
r = 2 | f + 1 = n + 3 ≡ 0 (8). So only **p ≡ 1 (mod 8)** matters.

**R3 (parity of words).** For n ≡ 1 (mod 8) a word with x, z both odd has y odd (reduce mod 2), so U₇ words have x even
(any y) or z even and 8 | y.

## 2. Theorem A — U₇ holds for almost all primes, exceptional set ≪ N (log N)^{−A} (PROVED; standard sieve)

**Theorem A (PROVED).** For every A > 0,
  #{p ≤ N prime : ¬U₇(p)} ≪_A N (log N)^{−A}.
More precisely, for K ≥ 1 put L_x := lcm(8, x) and κ_K := 1 + Σ_{x ≤ K} 1/φ(L_x). Then the number of primes p ≤ N for
which **no** x ≤ K and **no prime** ℓ ≡ −1 (mod L_x) with ℓ | p + x exist is ≪_K N (log N)^{−κ_K}, and κ_K → ∞.

*Proof.* (1) *Witness.* If ℓ | p + x with ℓ ≡ −1 (mod L_x), then (x, y, z) = (x, (ℓ+1)/x, (p+x)/ℓ) is a word:
xyz − x − z = (ℓ+1)z − x − z = ℓz − x = p, all letters positive integers, and xy = ℓ + 1 ≡ 0 (mod 8). So U₇(p).
(2) *Sieve set-up.* Let 𝒫 = {primes ℓ > 2K + 2}. For ℓ ∈ 𝒫 let Ω(ℓ) := {0} ∪ {−x mod ℓ : 1 ≤ x ≤ K, L_x | ℓ + 1}.
Since ℓ > K these classes are distinct, so ω(ℓ) := |Ω(ℓ)| = 1 + #{x ≤ K : L_x | ℓ + 1} ≤ K + 1 < ℓ/2. Let
𝒜 = {1, …, N}; for squarefree d composed of primes of 𝒫, 𝒜_d := {n ∈ 𝒜 : n mod ℓ ∈ Ω(ℓ) ∀ ℓ | d} has
|𝒜_d| = N ω(d)/d + R_d with |R_d| ≤ ω(d) (CRT: ω(d) classes mod d). By the prime number theorem in progressions
(fixed moduli L_x), Σ_{w ≤ ℓ < z, ℓ ∈ 𝒫} ω(ℓ) log ℓ / ℓ = κ_K log(z/w) + O_K(1). So the hypotheses (Ω₁) with A₁ = 2,
(Ω₂(κ)) with κ = κ_K, and (R) of Halberstam–Richert, *Sieve Methods*, Thm 2.2 (Brun's sieve upper bound; accessible
restatement: Richert, *Lectures on Sieve Methods*, §11, Thm 11.3 / (11.10), whose chapter notes identify it with H–R
Thm 2.2; also Halberstam–Richert, *A new look at Brun's sieve*, Thm 3) hold for each fixed K, giving
for 2 ≤ z ≤ N: S(𝒜; 𝒫, z) := #{n ∈ 𝒜 : n mod ℓ ∉ Ω(ℓ) ∀ ℓ ∈ 𝒫, ℓ < z} ≪_K N W(z),
W(z) := Π_{ℓ∈𝒫, ℓ<z}(1 − ω(ℓ)/ℓ) ≍_K (log z)^{−κ_K} (Mertens in progressions).
(3) *Counting.* Take z = N^{1/2}. A prime p ∈ (z, N] with no witness of the type in (1) for x ≤ K satisfies p mod ℓ ≠ 0
(ℓ < z < p) and p mod ℓ ≠ −x whenever L_x | ℓ + 1, for every ℓ ∈ 𝒫, ℓ < z; hence it is counted by S(𝒜; 𝒫, z).
So the count is ≤ z + S ≪_K N (log N)^{−κ_K}.
(4) *Divergence.* φ(L_x) ≤ L_x ≤ 8x, so κ_K ≥ 1 + (1/8) Σ_{x≤K} 1/x → ∞. Given A pick K with κ_K ≥ A. ∎

**Falsifier status of Theorem A.** It is a density statement: the odd squares (≈ √N) and the composite zeros are
null sets, so F1/F3/F4 are respected vacuously. **It is F2-blind:** restricting x to odd x or to 8 | x (pure U⁽⁸⁾
targets) the sum Σ 1/φ(L_x) still diverges, so the *same* proof shows U⁽⁸⁾ holds for all but ≪ N (log N)^{−A} primes —
and U⁽⁸⁾ is false at 45 primes ≤ 10⁸. Hence Theorem A (explicit witnesses, density 1) does not by itself establish, or
lead to, the all-primes statement; it is the U₇ analogue of the classical "ES for almost all n" results (Vaughan 1970
has the stronger N·exp(−c(log N)^{2/3}) for ES itself). Novelty: low — a standard fixed-dimension sieve specialization with K chosen after A, with a weaker saving than
Vaughan's for ES (an ES exceptional-set bound does not by itself imply Theorem A, since U₇ is narrower; priority for
the exact U₇ statement is not established); no pointwise mechanism. Recorded as the honest fallback the brief asks for
("positive proportion with an explicit mechanism"): explicit witnesses ℓ | p + x, x ≤ K(A).
*Corollary A′ (PROVED).* In every fixed reduced residue class a mod M, the primes with U₇ have relative density 1
(primes in the class ≫_M N/log N, exceptions ≪_A N (log N)^{−A}); in particular they are not contained in any finite
union of residue classes avoiding 𝔐.

## 3. Theorem B — polynomial word families in representation coordinates collapse (PROVED; known in other word forms)

**Prior art.** This is the U₇ word-form version of `Z58_MORDELL.md` Prop C1 (degree 2, (★) form 4UBC − U − B = f) and
`NORMFORM_CUBIC.md` Thm 1.1′ (any degree, Type II form). Nothing conceptually new; included because the lane's natural
first "p-adaptive" idea (choose the word from the Fermat representation p = a² + b², or from another representation)
is exactly what it excludes, and the U₇ corollary (via U₇(m²) = 0) is short. (Fermat representations do not by
themselves distinguish primes from squares: 25 = 3² + 4².)

**Theorem B (PROVED).** Let F ∈ ℚ[t₁,…,t_m] (independent variables) have degree d ≥ 2 and leading form F_d irreducible
over ℚ. If X, Y, Z ∈ ℚ[t] are nonzero and XYZ − X − Z = F identically, then at least two of X, Y, Z are constants.
*Proof.* Write d_X, d_Y, d_Z for the degrees. ℚ[t] is a domain, so deg(XYZ) = d_X + d_Y + d_Z and the leading form of
XYZ is X_top·Y_top·Z_top. Case max(d_X, d_Z) ≥ d, say d_X ≥ d_Z, d_X ≥ d: deg(F + X + Z) ≤ d_X (cancellation only
lowers it), so d_Y + d_Z ≤ 0 and Y, Z are constants. (Symmetric if d_Z is the maximum.) Case d_X, d_Z < d: then
F + X + Z has degree exactly d with leading form F_d, so d_X + d_Y + d_Z = d and F_d = X_top Y_top Z_top. As F_d is
irreducible, at most one factor is non-constant. ∎
*Applies to:* binary quadratic forms of non-square discriminant (e.g. a² + b²), also after invertible rational linear
changes of variables (non-invertible substitutions such as a = b = s can make the leading form reducible), quadratic
forms of rank ≥ 3 (a product of two linear forms has rank ≤ 2), full norm forms of number fields of degree ≥ 2.
*Not covered:* formulas valid only on an algebraic locus of the parameters (e.g. negative-Pell data (t, s) with
ps² − t² = −1 are not independent coordinates of an identity n = F(t, s); p = (t² + 1)/s² is not of this type), algebraic
non-polynomial formulas, piecewise rules, infinitely many families, representations with reducible leading form, and
rational families with integrality conditions — note X := (F + Z)/(YZ − 1) is a rational family for every Y, Z with
YZ − 1 ≢ 0, so rational families carry no restriction and the content is entirely the U₇ divisibility itself.

**Corollary B′ (PROVED).** Let 𝔉₁, …, 𝔉_J be polynomial word families as in Theorem B (each used on an arbitrary subset
D_j ⊂ ℤ^{m_j} of parameters, n = F_j(t) the represented integer, only specializations that are U₇ words — positive
integer letters, 8 | XY — count). Then there is M ≥ 1 such that no n ≡ 1 (mod M), n > M, receives a word from any 𝔉_j.
In particular infinitely many primes (Dirichlet) are missed.
*Proof.* Discard families with no valid specialization; in the rest, by Theorem B two letters are constants, and these
are positive integers (they are letters of a valid word). (a) X = x, Y = y constant: every produced word has
f = xy − 1 ≥ 7, f ≡ 7 (8), and forces n ≡ −x (mod f); since x | f + 1, (x/f) = 1 and (−1/f) = −1 (Jacobi facts as in
Z60 Lemma 7(ii); also for x = f + 1), so −x is a Jacobi non-residue mod f and n ≢ 1 (mod f). (b) X = x, Z = z constant:
n can be produced only if Y := (n + x + z)/(xz) is a positive integer with 8 | xY (the family is *contained in* this
ambient predicate); for n > xz the predicate depends only on n mod 8xz. (c) Y = y, Z = z: yz = 1 would force
y = z = 1 and F = XYZ − X − Z = −1, impossible; so yz − 1 > 0, and n can be produced only if X := (n + z)/(yz − 1) is a
positive integer with 8 | Xy — for n large a predicate depending only on n mod 8(yz − 1). In (b), (c) the ambient
predicate, true at n, gives a U₇ word for n; the period M_j is even, so for m ≡ 1 (mod M_j) large, m is odd and
m² ≡ 1 (mod M_j); U₇(m²) is false (Z60 Lemma 7(ii)), so the predicate is false on the class 1 mod M_j beyond the
threshold. Take M = lcm of all f's and M_j's, enlarged to exceed all thresholds. ∎
*Scope of the reading.* Finite menus of global polynomial identities in independent representation coordinates add
nothing beyond congruence classes of n. This does **not** exclude algebraic p-adaptivity in general (see "Not covered").

## 4. Lemma N — the norm chain a counterexample must satisfy (PROVED) and why it does not close

**Lemma N (PROVED).** Let p ≡ 1 (mod 8) with ¬U₇(p). Then
(i) every odd prime factor of p + 1 is ≡ 1 (mod 4); (ii) every prime factor of p + 2 is ≡ 1 or 3 (mod 8);
(iii) every prime factor of p + 4 is ≡ 1 (mod 4); (iv) the prime factors of p + 8 lie all in {1, 3} or all in {1, 5}
mod 8; (v) if 7 ∤ p then (p/7) = 1; if gcd(p, 15) = 1 then (p/15) = 1 (for primes p > 7 both guards hold; for general
n the guards must be read as written, e.g. (1465/15) = 0).
*Proof.* Shift form (Lemma 7(i)): ¬U₇ ⟺ for every x, p + x has no divisor ≡ −1 (mod L_x).
(i) If t ≡ 3 (mod 4), t | (p+1)/2, put x = 2t and d := p + 2t (a divisor of p + x). Then d ≡ 1 + 6 ≡ 7 (mod 8),
and d = (p + 1) + (2t − 1) ≡ −1 (mod t) since t | p + 1; t odd, so d ≡ −1 (mod 8t) = (mod L_{2t}) — a witness. So
(p+1)/2 (≡ 1 mod 4) has no divisor ≡ 3 (mod 4), i.e. no prime factor ≡ 3 (mod 4). (Note: the shift x = 2t is chosen
adaptively from the factorization of p + 1; (i) is not a single fixed-shift condition.)
(ii)–(iv) x ∈ {2, 4, 8}, L_x = 8: p + x has no divisor ≡ 7 (mod 8). A prime factor ≡ 7 (mod 8) is such a divisor, and
two distinct prime factors q ≡ 3, q′ ≡ 5 give qq′ ≡ 7. So the odd prime factors lie all in {1,3} or all in {1,5}
mod 8. p + 2 ≡ 3 (mod 8) excludes {1,5} (products of classes 1, 5 are 1 or 5); p + 4 ≡ 5 excludes {1,3}.
(v) Z60 Lemma 7(v) (complete moduli 7, 15). ∎
So a counterexample p would have p + 1 ∈ 2·N(ℤ[i]), p + 2 ∈ N(ℤ[√−2]), p + 4 ∈ N(ℤ[i]) (as integers all of whose prime
factors split). **Why this does not close:** by quadratic reciprocity each of (ii), (iii) says (p/q) = 1 for all
q | p + x (and (i) likewise for q | p + 1) — consistent with p prime — and such primes are plentiful: among the
1 439 970 primes p ≡ 1 (8) ≤ 10⁸, **41 866** satisfy (i)–(iii) and **15 468** satisfy (i)–(iv) (EVIDENCE,
`scripts/z68_u7o_normchain.c`, output `data/z68/u7o/normchain_1e8.txt`; first ones 1009, 3361, 3529, 3889, 9601 —
3361 is the first large least-witness record of §5 and 9601 the López-half prime of Z60). All are U₇, rescued by
other shifts (e.g. 1009: x = 3, f = 23 | 1012, word (3, 8, 44)). Whether all chain constraints (i)–(iv) are
simultaneously satisfied by infinitely many primes would follow from a Dickson/Schinzel-type hypothesis specialised to
this chain; this was not written out (Z60 Prop D treats fixed shifts, not the adaptive x = 2t of (i)). Lemma N is the
shape of the obstruction, not a route.

## 6. Pointwise attempts and exactly where they stop

None of the following reached the stage of a candidate rule to be run against K1–K4 (Assessment, not proofs).
* **Shift / slice / T-forms.** All reformulations (R1, the k-form f = (p + r)/k with r | p + k, the slices
  f ∈ (p/(k+1), p/k] where −p mod f = (k+1)f − p is linear in f, the T-form "gp + 1 has a divisor ≡ −1 mod lcm(8, g)")
  end at the same atom: *a specific integer (p + x, or gp + 1) has a divisor in a prescribed residue class whose modulus
  grows with the free parameter.* Finitely many fixed shifts give finitely many divisor-avoidance conditions, which
  Z60 Prop D shows can all fail together at infinitely many primes (unconditionally for f ≤ X; Dickson-conditionally for
  shift index and middle letter ≤ X). Nothing pointwise is available about one integer's divisors in a progression of
  modulus ≍ (its size)^θ; that is the B2 atom, untouched.
* **Primality-sensitive data (negative Pell t² + 1 = ps², Legendre: solvable for primes p ≡ 1 (4), unsolvable at odd
  squares).** Not covered by Theorem B (locus, not identity). The one natural try, g = s², gives gp + 1 = t² + 2; for
  p odd, t is even (t odd would make t² + 1 ≡ 2 (mod 4) = ps² with s² ≡ 2 (mod 4)), so t² + 2 ≡ 2 (mod 4); every odd
  prime q | t² + 2 has (−2/q) = 1, i.e. q ≡ 1, 3 (mod 8), so every odd divisor is ≡ 1, 3 (mod 8) and even divisors are
  not ≡ 7: no divisor ≡ −1 (mod lcm(8, g)) — a dead end (PROVED). Other combinations were not explored systematically.
* **Fermat / other representations, divisibility versions.** E.g. for f = xa − 1 (p = a² + b²) the condition f | p + x
  reads x²b² ≡ −(1 + x³) (mod xa − 1): the U₇ divisibility in new coordinates, no structural gain found.
* **Where primality could enter.** Every U₇ witness has (p/f) = −1 (Jacobi); non-squareness supplies some f with
  (p/f) = −1, but not that one of the τ(f + 1) − 1 admissible classes −r mod f is hit. The Z₇ composites are all
  divisible by 5 or 7, and 5 | n (resp. 7 | n) removes every f divisible by 5 (resp. 7) — a witness forces gcd(n, f) = 1
  — including the complete moduli 15 (resp. 7). None of the mechanisms here uses more than non-squareness, and none
  uses even that pointwise.

### 6A.1 Lemma C — fixed-letter searches are divisor searches (PROVED)
From xyz − x − z = n: n + z = x(yz − 1) and n + x = z(xy − 1). So the words with **z = c** are exactly: divisors
e = yz − 1 of n + c with e ≡ −1 (mod c), x = (n + c)/e, subject to 8 | xy; the words with **x = c** are divisors
d ≡ −1 (mod lcm(8, c)) of n + c; the words with **y = c** are divisors D ≡ −1 (mod lcm(8, c)) of cn + 1 (T-form).
Lemma N(i)'s adaptive shift x = 2t (t | (p+1)/2, t ≡ 3 mod 4) is the z = 1 word (2t, (p+1)/(2t) + 1, 1). So the
Lemma-N-type constructions — one letter fixed at c, the others read off a divisor of p + c or cp + 1 — are exactly the
words of R-casc_C. (An arbitrary letter that merely *divides* p + c need not come with a small letter, e.g. p = 73,
x = 2 | p + 1, word (2, 8, 5); such divisor-letter rules are R-Λ, handled separately by Cor K′.) Let
m(p) := min over U₇ words of min(x, y, z), with m(p) = ∞ if no word exists (the cascade depth at which p is first
killed).

### 6A.3 Prop K — no bounded cascade can close (CONDITIONAL on Dickson's conjecture; numerically illustrated)

**Prop K.** Let C ≥ 1 and M := lcm(840, {8k(k+1) : 1 ≤ k ≤ C}). Assume Dickson's conjecture for the linear forms
Mt + 1, (M/(k+1))t + 1, (kM/(k+1))t + 1 (1 ≤ k ≤ C). Then there are infinitely many primes p ≡ 1 (mod M) (so p ∈ 𝔐)
with m(p) > C, i.e. **every U₇ word of p has all three letters > C**.
*Proof.* All forms take the value 1 at t = 0, so their product has no fixed prime divisor and the system is admissible;
Dickson gives infinitely many t ≥ 1 with all values prime. Put p = Mt + 1, q_k := (p + k)/(k+1) = (M/(k+1))t + 1,
Q_k := (kp + 1)/(k+1) = (kM/(k+1))t + 1 — primes, ≡ 1 (mod 8k) because 8k | M/(k+1), and > k + 1.
Every divisor of (k+1)q_k (resp. (k+1)Q_k) is e or e·q_k (e·Q_k) with e | k+1, hence ≡ e (mod 8k), with 1 ≤ e ≤ k + 1.
*x = k:* a word needs a divisor ≡ −1 (mod L_k), L_k = lcm(8, k) | 8k, so e ≡ −1 (mod L_k) with e ≤ k + 1, i.e.
e = L_k − 1 ≤ k + 1. L_k ∈ {k (8 | k), 2k, 4k, 8k} and L_k ≥ 8: if 8 ∤ k, L_k ≥ 2k > k + 2 for k ≥ 3 and L_k = 8 > k + 2 for k ≤ 2;
if L_k = k then e = k − 1 | k + 1 forces k ≤ 3, contradicting 8 | k. *y = k:* identical with Q_k (T-form).
*z = k:* e′ := yk − 1 is a divisor of p + k = (k+1)q_k with e′ ≡ −1 (mod k), so its e satisfies e ≡ −1 (mod k),
e | k + 1. For k ≥ 4 the only candidate e ≤ k + 1 with e ≡ −1 (mod k) is k − 1, and k − 1 | k + 1 forces k ≤ 3.
k = 1: e′ ∈ {1, 2, q₁, 2q₁}, (x, y) = ((p+1)/e′, e′ + 1) = (2q₁, 2), (q₁, 3), (2, q₁ + 1), (1, 2q₁ + 1); since
q₁ ≡ 1 (mod 8), v₂(xy) = 2, 0, 2, 0 — never ≥ 3. k = 2: p + 2 = 3q₂ is odd, so x is odd and 8 | y = (e′+1)/2 needs
e′ ≡ 15 (mod 16); but e′ ∈ {1, 3, q₂, 3q₂} with q₂ ≡ 1 (mod 16) gives e′ ≡ 1, 3 (mod 16). k = 3: p + 3 = 4q₃,
q₃ ≡ 1 (mod 24); e′ ≡ 2 (mod 3) leaves e′ ∈ {2, 2q₃}; e′ = 2: y = 1, x = 2q₃, v₂(xy) = 1; e′ = 2q₃: x = 2 and
y = (2q₃ + 1)/3 with 2q₃ + 1 ≡ 3 (mod 48), so y is odd, v₂(xy) = 1. ∎
(This is Z60 Prop D (a, T) re-done for U₇ and extended to the third letter z, which is where Lemma N's adaptive shifts
live.)

**Lemma S (size, PROVED).** Let (x, y, z) be a U₇ word of n, B ≥ 1 an integer. If x ≥ n/B or z ≥ n/B then the other two letters
satisfy min ≤ 2B + 2; if y ≥ n/B and n > B(B+3)/2 then min(x, z) ≤ B + 1.
*Proof.* x ≥ n/B and y, z ≥ 2B + 3: x(yz − 1) ≥ (n/B)((2B+3)z − 1) > (n/B)·2Bz = 2nz ≥ n + z, contradicting
n + z = x(yz − 1). z symmetric (n + x = z(xy − 1)). y ≥ n/B, x, z ≥ B + 2: n = x(yz − 1) − z ≥
(B+2)((n/B)z − 1) − z ≥ nz + 2nz/B − B − 2 − z ≥ n − 3 + 2nz/B − B > n when nz > B(B+3)/2 (using nz ≥ n + z − 1). ∎

**Corollary K′ (CONDITIONAL on Dickson).** Fix C₀ and let Λ_{C₀}(p) := {1,…,C₀} ∪ {L : L | p + c or L | cp + 1 for some
1 ≤ c ≤ C₀}. There are infinitely many primes p ∈ 𝔐 with **no** U₇ word having a letter in Λ_{C₀}(p).
*Proof.* Prop K with C := 2C₀ + 4. Divisors of p + c = (c+1)q_c and cp + 1 = (c+1)Q_c are ≤ c + 1 ≤ C or
≥ min(q_c, Q_c) ≥ p/(C₀ + 1). A letter ≤ C is excluded by Prop K; a letter ≥ p/B, B = C₀ + 1, forces (Lemma S, p large)
another letter ≤ 2B + 2 = C, excluded. ∎
**Consequence.** Every cascade of the requested type — adaptive shifts x, adaptive g in gp + 1, or third letters,
drawn from divisors of p + 1, p + 2, p + 4, p + 8, …, cp + 1 for c up to any fixed bound (and multiples jL, j ≤ H, of
them: take C = max{H(C₀ + 1), 2C₀ + 4}) — fails K5: it cannot close at a finite depth unless Dickson's conjecture fails
for an explicit admissible system. Conditionally on Dickson, the 0 survivors at depth 26 up to 4·10⁹ is a finite-range artefact (unconditionally it is
just EVIDENCE about [1, 4·10⁹]; the 4·10⁹ census was not independently rerun by the cross-model review, which
verified the records, the deep primes and a random sample).
*Numerical illustration* (`scripts/z68_u7o_dickson.c`, `data/z68/u7o/dickson_C{3,4}.txt`): C = 3 (M = 3360, 6 forms):
the first 12 such primes (71 628 481 … 858 080 161) all have m(p) = 4 or 5 > 3; C = 4 (8 forms): 10 primes

### 6A.5 Negative Pell beyond g = s² (PROVED obstructions for specific branches; not a blanket exclusion)
**Lemma P.** Let p ≡ 1 (mod 4) be prime and t² + 1 = ps² (t, s ≥ 1; exists by Legendre).
(i) For odd f with gcd(f, s) = 1: (p/f) = ((t² + 1)/f) (Jacobi; (s²/f) = 1). A prime q | gcd(f, s) has q | t² + 1,
so q ≡ 1 (mod 4).
(ii) If f is odd, gcd(f, s) = 1 and f | t ± c, then (p/f) = ((c² + 1)/f). For c = 0, ±1 coprimality is automatic for odd f (an
odd prime q | gcd(t, s) would divide t² + 1 − t² = 1; an odd prime q | gcd(t ± 1, s) would divide t² + 1 with t ≡ ∓1,
hence 2), and for f ≡ 7 (mod 8) the symbol is 1 resp.
(2/f) = 1, so no such f is a U₇ witness (a witness needs (p/f) = −1). For larger c, and without coprimality, nothing
is excluded: e.g. p = 41, t = 32, s = 5, f = 15 | t − 2 is an actual U₇ witness (−41 ≡ 4 mod 15, 4 | 16).
(iii) g = c·s² in the T-form needs (g − 1)² ≤ (xg − 1)(zg − 1) = gp + 1, i.e. c s² ≤ p + 2. For the minimal solution
this fails unless s ≤ √(p + 2) (only primes with an unusually small fundamental unit); when it holds, it is the generic
T-form at one value of g. (iv) c = 1: t is even (t odd ⟹ t² + 1 ≡ 2 (mod 4) = ps², impossible), every odd prime
q | t² + 2 has (−2/q) = 1, so odd divisors are ≡ 1, 3 (mod 8) and no divisor is ≡ 7 (mod 8).
So excluded are: g = s² (iv); f | t, f | t ± 1 (ii); g = c s² whenever c s² > p + 2 (iii) — e.g. the standalone family
g = c s² fails at p = 41 (s = 5 forces c = 1, excluded by (iv)). Not excluded: g = c s² with small s (p = 17, t = 4,
s = 1, g = 2 gives the word (4, 2, 3)) and divisors of t ± c for c ≥ 2. Global polynomial two-squares identities are
excluded by Theorem B; other two-squares-derived rules are not.
