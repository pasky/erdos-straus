## 4. What an arbitrarily large joint class menu can see

**Theorem B (PROVED rel. imaginary ring class field theory and Chebotarev).** Let L be the compositum of *any finite number* of ring class fields of imaginary quadratic orders, with arbitrary conductors and arbitrary base fields; subfields of this compositum are allowed as data. If instead these are Hilbert class fields of the maximal orders, every abelian subextension has exponent dividing **2**. *Proof of the 4-bound.* Put G=Gal(L/ℚ), embedded in the product of generalized dihedral groups Gᵢ=Aᵢ⋊⟨cᵢ⟩, where Aᵢ is the ring class group and actual complex conjugation c on L restricts to cᵢ, acting by inversion (Cox, *Primes of the Form x²+ny²*, Lemma 9.3). For any g∈G, **g² is in every rotation group** upon projection. Therefore c g² c⁻¹=g⁻² coordinate by coordinate, and g⁴ is a commutator. This bounds the *joint* abelianization and works without any disjointness or rank assumptions. It is not the incorrect assertion that exponent two is preserved in a subdirect product.

*Proof of the 2-bound.* If l is unramified in all the order conductors (i.e. l divides none), inertia in each class field restricts injectively to inertia in its quadratic base over ℚ: the relative extension is unramified there. In particular its image has exponent ≤2. Every element of inertia in the compositum thus squares to the identity. For a Hilbert-only menu this holds at **every finite prime, including 2**. The finite inertia subgroups generate the abelianization, since the remaining abelian quotient would be unramified at every finite prime of ℚ (trivial by Minkowski).
