## 1. Equivalent forms (all PROVED; elementary)

**Lemma 1 (symmetric form).** Let n be odd. Then
(a) U₇(n) ⟺ ∃ x, z ≥ 1 with lcm(8, xz) | n + x + z.
(b) For n ≡ 1 (mod 8): U₇(n) ⟺ ∃ x, z ≥ 1 with xz | n + x + z and x + z ≡ 7 (mod 8).
(c) Any such pair has gcd(x, z) | n, exactly one of x, z even, and (x mod 8, z mod 8) ∈ {(0,7), (4,3), (2,5), (6,1)} up
to swapping. The pairs with 8 | x or 8 | z (type (0,7)) are exactly the U⁽⁸⁾ "8 | x" words; the other three types are
the targets a proof must use (Z60 §4.2).
(d) ("sum–product" form) For n ≡ 1 (8): U₇(n) ⟺ ∃ k ≡ 7 (mod 8), ∃ 1 ≤ x < k with x(k − x) | n + k ⟺ ∃ k ≡ 7 (8) and
a divisor m of n + k with k² − 4m a perfect square.

*Proof.* (a) If (x, y, z) is a word with 8 | xy then xz | n + x + z = xyz and 8 | xyz, so lcm(8, xz) | n + x + z.
Conversely, if lcm(8, xz) | n + x + z put y = (n + x + z)/(xz); then xyz = n + x + z and 8 | xyz. If z is odd, 8 | xy; if
x is odd, 8 | yz and (z, y, x) is a word with 8 | (first)(second); if both were even then n + x + z would be odd,
contradicting 8 | n + x + z. (b) n ≡ 1 (8) and 8 | n + x + z ⟺ x + z ≡ 7 (8); conversely x + z ≡ 7 (8) gives
8 | n + x + z. (c) g = gcd(x,z): g² | n + x + z and g | x + z give g | n. x + z odd forces one even letter; the list
is x + z ≡ 7 (8). The type (0,7) pair (x, z) = (8a, z) is the word (8a, y, z), i.e. the "8 | x" half of U⁽⁸⁾
(Z60 Lemma 7(iv): targets r = 8a | f+1); type (4,3) etc. have v₂(x) ≤ 2 and v₂(y) = 3 − v₂(x) possible. (d) Put
k = x + z; x(k − x) = xz; the divisor m = xz of n + k has k² − 4m = (x − z)². ∎

**Lemma 1′ (modular hyperbola / continued-fraction form).** For f ≡ 7 (8) coprime to n write a = (−n mod f),
b = (−n⁻¹ mod f) ∈ [1, f−1]. Then ab ≡ 1 (mod f), so ab ∈ {1, f+1, 2f+1, …}, and
  f is a U₇ witness of n ⟺ ab = f + 1 (or ab = 1, i.e. f | n + 1).
Equivalently: a | f+1 ⟺ b = (f+1)/a. In continued-fraction terms, with t = ⌈n/f⌉, s = (f+1)/a:
  n/f = [t − 1; 1, s − 2, 1, a − 1]   (for a, s ≥ 2),
so the U₇ witnesses are precisely the denominators f ≡ 7 (8) for which n/f has a continued fraction of the shape
[·; 1, ·, 1, ·]; the swap a ↔ t (x ↔ z) reverses the fraction and exchanges f = as − 1 with f′ = ts − 1, the two
factors of sn + 1.

*Proof.* a | f + 1 and ab ≡ 1 give ab ≡ 1, 1 ≤ ab ≤ (f−1)², and ab = f + 1 iff b = (f+1)/a; conversely ab = f + 1 gives
a | f+1. The CF: with f = as − 1, (f − a)/f = [0; 1, s − 2, 1, a − 1] by direct expansion (f/(f−a) = 1 + a/(f−a),
(f − a)/a = s − 2 + (a−1)/a, a/(a−1) = 1 + 1/(a−1)), and n/f = (t − 1) + (f − a)/f since n = ft − a. ∎

Remarks. (i) Lemma 1′ says a hit is the event that the point (−n, −n⁻¹) mod f lies on the *lowest* branch
XY = f + 1 of the modular hyperbola XY ≡ 1 (mod f); Kloosterman-type equidistribution of (a/f, b/f) predicts the
hit probability (1 + log f)/f for a "generic" f, matching the arithmetic count (τ(f+1) − 1)/f on average — and shows
why equidistribution results (error ≫ f^{1/2}) cannot detect a single hit (§3.3). (ii) None of Lemma 1/1′ is deep;
their use here is to make the symmetry x ↔ z and the role of the 2-adic condition transparent. The (x,z)-form (F1) of
LORENZINI_W.md is Lemma 1(a) without the 8-condition.

**Lemma 2 (small shifts: exact failure conditions).** Let p ≡ 1 (mod 8) be prime. For the words with a fixed small
letter the U₇ condition is a divisor condition on one shifted integer; in the cases below it is equivalent to a
*norm-form* condition. Each line: [word family] — [U₇ holds via this family iff] — [fails iff].
* z = 1 (words (x, y, 1)): (p+1)/2 has a divisor ≡ 3 (mod 4) — fails iff (p+1)/2 ∈ S_{{1} mod 4} iff p + 1 = u² + v²
  (u, v odd).
* z = 2: p + 2 has a divisor ≡ 5 (mod 8) [equivalently ≡ 7 (8), equivalently ≡ 15 (16)] — fails iff p + 2 ∈ S_{{1,3} mod 8}
  iff p + 2 = u² + 2v².
* z = 4: p + 4 has a divisor ≡ 3 (mod 8) [equivalently ≡ 3 (4)] — fails iff p + 4 ∈ S_{{1} mod 4} iff p + 4 = u² + v².
* z = 3: (p+3)/4 has a divisor ≡ 2 (mod 3) — fails iff (p+3)/4 ∈ S_{{1} mod 3} iff (p+3)/4 = u² + 3v² (p ≡ 1 mod 3).
* y = 2: 2p + 1 has a divisor ≡ 7 (8) — fails iff 2p + 1 ∈ S_{{1,3} mod 8} iff 2p + 1 = u² + 2v².
* y = 4: 4p + 1 has a divisor ≡ 7 (8) — fails iff 4p + 1 ∈ S_{{1} mod 4} iff 4p + 1 = u² + v².
* y = 8: 8p + 1 has a divisor ≡ 7 (8) — fails iff 8p + 1 ∈ S_{{1,3}} ∪ S_{{1,5}} (mod 8), iff 8p + 1 = u² + 2v² or u² + v².
* x = 8: p + 8 has a divisor ≡ 7 (8) — fails iff p + 8 ∈ S_{{1,3}} ∪ S_{{1,5}}.
* y = 1 and x = 1 are implied by z = 1 (both need a divisor ≡ 7 (8) of (p+1)/2).
Consequently a **U₇-zero prime p ≡ 1 (8) would satisfy simultaneously**: p + 1, p + 4, 4p + 1 are sums of two
squares; p + 2, 2p + 1 are of the form u² + 2v²; (p+3)/4 = u² + 3v²; 8p + 1 and p + 8 are each of the form u² + v² or
u² + 2v². (Numerically checked for all odd n ≤ 10⁶ against the word enumeration: `scripts/z68_u7f_smallshift.py`.)

*Proof.* Use Lemma 1 in the form: a word with letter z is a pair (x, z) with x | p + z, z | p + x, x + z ≡ 7 (8);
equivalently a divisor c := (p + z)/x of p + z with c ≡ −1 (mod z) and v₂(x) + v₂(c + 1) ≥ 3 (because
8 | p + x + z = x(c + 1)). z = 1: p + 1 = 2m, m ≡ 1 (4) odd; x + 1 ≡ 7 (8) forces x = 2x′ with x′ | m, c = m/x′, and
8 | 2x′(c+1) ⟺ c ≡ 3 (4). m has a divisor ≡ 3 (4) iff it has a prime factor ≡ 3 (4); otherwise m ∈ S_{{1} mod 4}, i.e.
m = a² + b², p + 1 = (a+b)² + (a−b)². z = 2: p + 2 odd, x odd divisor of p + 2 with x ≡ 5 (8); p + 2 ≡ 3 (8); the
subgroups of (ℤ/8)^× not containing 5 whose elements can multiply to 3 are only {1,3}; hence no divisor ≡ 5 (8) ⟺
all prime factors ≡ 1, 3 (8) ⟺ (classically) p + 2 = u² + 2v²; and "divisor ≡ 7 (8)" / "≡ 15 (16)" give the same set
(the cofactor of a 5 is a 7, and a 7 with the complementary odd part gives a 15 mod 16 after at most one more
adjustment — direct check of the three subgroup cases). z = 4: x ≡ 3 (8), x | p + 4 ≡ 5 (8); subgroups avoiding 3 that
can produce 5: only {1,5} = {1 mod 4}, so fails iff p + 4 ∈ S_{{1} mod 4}. z = 3: p + 3 = 4m, m ≡ 1 (6); x ≡ 4 (8) so
x = 4x′, x′ | m, c = m/x′ ≡ −1 (3); m has a divisor ≡ 2 (3) iff a prime factor ≡ 2 (3). y = 2, 4, 8: (xy − 1)(yz − 1) =
py + 1 with 8 | xy; for y = 2, 4 | x, the factor 2x − 1 ≡ 7 (8); for y = 4, 2 | x, 4x − 1 ≡ 7 (8); for y = 8 any x,
8x − 1 ≡ 7 (8); conversely a divisor d ≡ 7 (8) of py + 1 gives x = (d+1)/y with 8 | xy. The subgroup analysis mod 8 as
before (2p + 1 ≡ 3, 4p + 1 ≡ 5, 8p + 1 ≡ 1 (mod 8)). x = 8: f ≡ 7 (8), f | p + 8, as for y = 8. The norm-form
translations are the classical characterisations of integers represented by u² + v², u² + 2v², u² + 3v² (all prime
factors in the kernel of the corresponding character, here with the extra parity/coprimality automatically satisfied
since the numbers are odd or have 2-part exactly 2; (p+3)/4 is coprime to 6). ∎

## 3. Attack log — what was tried, and the exact point where each line breaks

The §1 forms make the target completely explicit: find coprime x, z with lcm(8, xz) | p + x + z. Every attempt
below is one way of choosing (x, z) adaptively from p. Labels: PROVED for the negative statements.

### 3.1 One-shift mechanisms are sieve statements; their union over a bounded set of shifts is a finite covering
For a fixed letter z (or x, or y) the condition is "p + z has a divisor c ≡ −1 (mod z) with
v₂((p+z)/c) + v₂(c+1) ≥ 3" (proof of Lemma 2). Union over z ≤ Z and x ≤ X (both letters bounded) is a finite union
of congruence classes p ≡ −x − z (mod lcm(8, xz)); p ≡ 1 (mod 8·lcm(xz : x, z ≤ Z)) avoids all of them (the only
coprime pairs with xz | x + z + 1 are (1,1), (1,2), (2,3), none with x + z ≡ 7 (8)). Hence **(PROVED)** no proof can
use only words with both x and z bounded: it fails on a positive-density set of primes (Dirichlet) — and indeed on
every residue class containing squares. One bounded letter leaves a genuinely non-congruence condition (Lemma 2), but
§2 shows what that condition can and cannot deliver: it is satisfied for all but ~(log p)^{−1/2} of primes per shift,
and the shifts' failures are *positively* correlated at hard primes (Z60 §3). The 43 primes ≤ 10⁶ in §1 that fail all
eight smallest families are the tip of this tail. No mechanism here.

### 3.2 Algebraic (polynomial) constructions from representation data are impossible — PROVED
Lemma 2 says a hard prime carries representations p + 1 = u² + v², p + 4 = u′² + v′², 4p + 1 = …, p + 2 = a² + 2b²,
(p+3)/4 = c² + 3d², …. A natural hope is to build the word from such data: (x, y, z) = polynomials in (u, v) with
p = u² + v² − 1. This cannot work:

**Proposition 3.2.** Let N(u, v) be u² + v² − 1 (or any of the shifted norm forms of Lemma 2) and let X, Y, Z ∈ ℚ[u, v]
be polynomials such that for all integer (u, v) in some residue class 𝒞 mod M (with N(u,v) ≡ 1 mod 8 on 𝒞),
(X, Y, Z)(u, v) is a U₇ word of N(u, v) whenever N(u, v) is prime. Then the same identity holds on all of 𝒞 (polynomial
identity XYZ − X − Z = N and 8 | XY, both Zariski-closed conditions, hold on the Zariski-dense set of (u,v) ∈ 𝒞 with
N prime — assuming, as for all such identities, that 𝒞 contains infinitely many (u, v) with N(u,v) prime; otherwise
the hypothesis is void), so it produces U₇ words at every odd square N(u, v) = m² with (u, v) ∈ 𝒞. The quadric
u² + v² − m² = 1 is isotropic and indefinite; its integer points are dense in every residue class of solutions
mod M (strong approximation for the spin group, Kneser; concretely the two-parameter family
(u, v, m) = (jk + … ) obtained from k(u + k) = j(j+1) covers each class — we used the standard theorem rather than
an explicit parametrisation). Such (u, v) exist in 𝒞 with m odd, contradicting U₇(m²) = 0 (Lemma 7(ii) of Z60). ∎

Consequence: any word construction must use the *prime factorisation* of some p + k (or kp + 1), not just a
representation — i.e. it is a divisor-in-progression statement about a shifted prime, the sieve-type statement of
§3.1. (Schinzel's theorem that no polynomial identity covers a class containing squares is the one-variable case;
this is the same argument one level up.)

### 3.3 Counting / equidistribution cannot see one hit
By Lemma 1′, the hit at f is the event that (−p mod f, −p⁻¹ mod f) lies on the branch XY = f + 1 of the modular
hyperbola. The pairs (a/f, ā/f) equidistribute in [0,1]² with error O(f^{1/2+ε}) (Weil–Kloosterman), while the
branch carries τ(f+1) − 1 ≈ log f points among φ(f): an event of probability ≈ (log f)/f. Averaged over p (or
over f in a long range) the main term Σ_f τ(f+1)/f ≍ log² F is fine; pointwise in p the error per modulus exceeds
the target by f^{1/2}. The square obstruction shows this is not an artefact: any main-term-plus-error count whose
main term does not carry the factor (1 − (p/f))/2 must be wrong by its whole main term at n = m². With the Jacobi
factor, the problem becomes a character sum Σ_{f ≤ F} (f/p) w(f) (reciprocity, p ≡ 1 (4)) over f ≡ 7 (8) *with the
tied weight w(f) = 1[(−p mod f) | f+1]* — the weight itself depends on p, so Burgess/Pólya–Vinogradov do not apply.
(Assessment; this is the usual B2 wall, reached here from the symmetric form.)

### 3.4 Descent / transfer: none exists in the natural coordinates
The hit set T_f = {−r mod f : r | f+1} is invariant under n ↦ n⁻¹ (mod f) (Z60 Prop E) and under nothing else
natural: not under n ↦ n + c, n ↦ cn, n ↦ (n − a)/b. Words of n and of n ± f correspond (z ↦ z ± 1) — periodicity, not
descent. The Vieta-type move for xz | p + x + z, (x, z) ↦ (x, (p+x)/z), stays in the solution set iff x | p − 1, and
then produces the complementary divisor with the *same* 2-adic type, so it cannot convert a type-(1,…) pair into a
U₇ pair. The map (x, z) ↦ (z, (p+z)/x) stays in Λ(p) iff z | p − 1. No descent to a smaller n exists either: an
integer n is a U₇-zero iff n lies in the measure-zero compact set 𝒰 = ∩_f (ℤ/f ∖ T_f) of the profinite completion;
𝒰 contains the profinite squares and much more, and "p ∉ 𝒰" is a statement about one specific integer avoiding a
null set — there is no smaller instance to reduce to. (PROVED where stated; Assessment for the last sentence.)

### 3.5 Fermat/Euler/cyclotomic control of factorisations gives only the trivial word
The only shifted values of p whose factorisations are controlled by primality are multiples of p and cyclotomic
values Φ_n(p). We checked each y-form candidate yp + 1 ∈ {(p−1)², (p+1)², (2p±1)², (ap±1)², Φ₃(p) = p² + p + 1 (y = p+1)}:
the divisors ≡ −1 (mod lcm(8, y)) are forced to be ≈ p and the only solution is the trivial word (1, p+2, 1), which
has 8 | xy iff p ≡ 6 (8). Prime factors of Φ_n(p) are ≡ 1 (mod n) — the wrong direction (they can never supply the
residue −1 mod 8 for n divisible by 8). Shifts r > p are dead in general: c ≡ −1 (mod r), c | p + r forces
c = r − 1 | p + 1, i.e. z = 1. (PROVED, routine.)

### 3.6 The smooth-part reduction: where the non-congruence input is located — PROVED
Write p + r = s_r · Q_r with s_r the y-smooth part. If Q_r is prime then
  shift r hits ⟺ ∃ e | s_r with e ≡ −1 (mod L_r), or ∃ e | s_r with p + r ≡ −e (mod L_r)   (L_r := lcm(8, r)),
because the divisors of p + r are e and eQ_r (e | s_r), and eQ_r ≡ −1 ⟺ p + r = s_rQ_r ≡ −s_r/e. The right-hand
side depends only on s_r and on p mod L_r. Hence for p ≡ 1 (mod M), M := lcm over r ≤ R of L_r·(all y-smooth
numbers ≤ p + R)… more simply: for p ≡ 1 (mod lcm(8, 1, …, R)·∏_{q ≤ y} q^{⌊log_q(2p)⌋}) the shift-r hit conditions
are the same as for n = 1 (a square), so **every witness with a letter ≤ R must use a proper factorisation of the
y-rough part of some p + r** (r ≤ R): the witness contains a prime factor > y of p + r and so does its cofactor.
This is Z60's Prop D in a sharper form: the only non-congruence input a proof can use is the *residue mod L_r of
the large prime factors of the shifted values p + r* (equivalently, by (−r/q) = (p/q) for q | p + r: the exact
class mod 8r of q, not merely its Jacobi symbol). §2 adds that a single large prime factor in the class −1 is not
what rescues the hard primes — it is a product q·Q with q small and Q large in the class −q⁻¹ (mod L_r)
(all 231 prime-witness-free primes ≤ 10⁹ have an ω(f) ≤ 2 witness; e.g. p = 2521: 87 = 3·29 | p + 2).

### 3.7 Things that were *not* found
No p-adaptive rule (continued fraction of p/k or √(kp), least nonresidue, Gaussian factorisation of p + 1, factor of
p ± 2^j) was found whose output is always a witness; each candidate rule is a one-shift sieve statement in disguise
(§3.1) or fails the square test (§3.2). The lane produced no mechanism, and §3.1–3.6 say precisely why the natural
mechanism classes cannot work.

## 4. Two new negative facts (CERTIFIED) and one sharper positive target (CONJECTURE)

**4.1 Prime witnesses are not enough.** 231 primes p ≡ 1 (8) ≤ 10⁹ have no prime U₇ witness q ≡ 7 (8) at all
(`data/z68/u7f/noprime_primes_1e9.txt`; counts 66 / 118 / 231 at 10⁷ / 10⁸ / 10⁹, growing ≈ N^{0.27}). Any proof
whose output is a prime f — "some p + r has a prime factor ≡ −1 (mod lcm(8,r))", or any Chebotarev-type argument
about prime factors of shifted primes — is dead at these primes. Heuristically the count of prime witnesses up to Q
has mean ≍ log Q, so P(none) ≍ Q^{−c} with c < 1, and the set is infinite (CONJECTURE, consistent with the growth).

**4.2 All four 2-adic pair types are necessary.** Partition U₇ pairs {x, z} by the residue mod 8 of the even letter:
0, 4, 2, 6 (Lemma 1(c)). For each type there is a prime ≤ 10⁷ whose *only* witnesses (f ≤ 2p+1) are of that type:
type 0: 5569, 68161, 534601; type 4: 83449, 96769, 1095481; type 2: 193, 673, 2521, 28921; type 6: 21841, 225289.
No further single-type prime appears in (10⁷, 10⁹] (12 in total), so each type's "half" fails only finitely often
as far as the data go — but a proof restricted to any three of the four types is false. This refines Z60's two-half

**4.3 Sharper target (CONJECTURE U₇^{(≤2)}).** Every prime p ≡ 1 (8) has a U₇ witness f with ω(f) ≤ 2
