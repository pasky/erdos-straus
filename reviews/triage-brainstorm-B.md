## 0. Cross-cutting findings (read this first)

### 0.1 Calibration of the DISAGREE verdicts
9 of 26 memos get DISAGREE. In **every** case the reason is *scope overreach of the barrier citation*, not a newly
found escaping mechanism. The recurring pattern: a memo shows that one natural instantiation (a fixed slice, a
fixed form, a fixed ambient set, a power-error asymptotic) collapses, then writes "COLLAPSES to B2/B3" for the whole
angle. But redteam-automorphic-2 Thm 2.2(iii) requires a parameter set **Θ₀ fixed independently of p** (and is
CONDITIONAL on H). CONDITIONAL_ES Prop 2.3 (B3) constrains *main terms of bounded-multiplicity detectors on almost
all primes*; it gives no error lower bound, and its Remark 2.4 keeps "small main term + smaller error" open.
LONGSHOT_PIGEONHOLE Thm 2.2 (B4) is about *transparent coset-covering* certificates. LONGSHOT_FIBRED Thm 3.1 is
about arithmetic-group orbits with a covolume count. None of these excludes a growing family Θ(p) at fixed p, a
target-specific hitting argument, or a non-power-asymptotic certificate.
**However:** each surviving residue is, on inspection, an instance of the already-listed open hatches H-A (growing
family), H-B (parity-breaking at fixed p), H-D (non-abelian) or H-F (integral geometry beyond BM). **No memo in this
half contains a concrete mechanism that escapes the barriers *and* comes with a plausible arithmetic input.** The
DISAGREEs are corrections to the ledger wording ("COLLAPSES" should read "the displayed instantiation collapses;
the general mechanism reduces to H-x, open"), not discoveries. Recommendation: when these memos are cited, the
verdict should be downgraded from "COLLAPSES" to "PARTIAL → H-x".

### 0.2 An error in the shared barrier text (affects all briefs)
The B2 text in the briefs says "a lottery with only polylog(p) expected winners (Σ_{p≤N} f(p) ≍ N log³N)". Over
**primes** Elsholtz–Tao give `N log²N ≪ Σ_{p≤N} f(p) ≪ N log²N log log N` (and the campaign's (D)32b removes the
log log for Type I). So the *average* of f(p) is ≍ log³p, but the displayed sum is wrong by a log. Spotted by the
part-3 reviewer in `tech_maynard_theta.md` §2, which inherits it. Harmless for the qualitative barrier; should be
fixed in the brief template and any memo quoting it.

### 0.4 The one structural observation worth keeping (from nonab_frobenius_redei)
T1 (odd squares) is passed by every *abelian* Frobenius condition only because "C contains no squares" is, for an
abelian group, detected by a quadratic character, i.e. by genus/congruence data, which Thm M/C already exclude. In a
group with trivial (or small) abelianisation such as A₅, there are conjugacy classes containing no squares that are
**invisible to every character of the abelianisation**. So "Frob_p ∈ C" with C square-free is (a) automatically false
at "Frob_{ℓ²}" for every ℓ, i.e. passes T1 for free, and (b) not congruence data. This is the cleanest statement in
this half of why hatch H-D is not closed. It does not supply an ES mechanism: one still needs a non-abelian
extension whose Frobenius *controls* Type I/II solvability, and no candidate exists (ET's varieties are toric/quadric).
