# Z60_MS105T — tryhard lane MS105T (wave z60)

**Problem (MS105).** Every sufficiently large non-square n ≡ 1 (mod 4) with gcd(n,105)=1 has d ≡ 3 (mod 4), d ≥ 3,
such that k := (−n mod d) ∈ [1, d−1] divides (d+1)/4. Equivalently n = 4uBC − u − B has a solution in positive integers.
(For n = p prime this would give ES for large p. ES is OPEN; nothing here claims it.)

Status labels: PROVED / CONDITIONAL / CERTIFIED (exact computation, script named) / EVIDENCE.

## §0 Mandatory falsifiers (stated at first commit; re-checked in §9)

* **F1 (squares, near-squares s·m²).** Every step claimed below must state where non-squareness enters. The basic
  mechanism is the Jacobi identity of §2 (Lemma 2.2): any solution forces (uk/n) = −1 (when gcd(uk,n)=1); for n = m² this is
  impossible, for n = s·m² it reduces to (uk/s)·(…) = −1, which is satisfiable — so any argument whose only use of
  "non-square" is "some Jacobi symbol (·/n) is −1" must additionally produce the *specific* (u,k) shape, and must be tested
  on n = s·m² with s ∈ {11,13,17,…}.
* **F2 (C even).** The C-even sub-family fails at primes > 10¹⁰ (data/z58/screens/r8_zeros_1e10.txt). Any covering
  argument must be checked to use odd C somewhere essential, or it proves a false statement.
* **F3 (composite zeros).** CERTIFIED here (scripts/z60_ms105t_zeros.c, data/z60/ms105t/zeros_le3e7.txt; matches the
  z58 list of 285 composites ≤ 7 999 801 exactly): up to 3·10⁷ there are 361 non-square zeros, 38 of them coprime to 105
  (14 primes, 24 composites, e.g. 2929 = 29·101, 752257 = 11²·6217, 3210601 = 19·37·4567, 12538801 = 11·47·79·307,
  29210401 = 11·31·85661). So no "gluing" lemma of the form "n₁, n₂ good ⇒ n₁n₂ good" can hold, and products of primes
  ≡ 1 (4) are no easier (2929, 5161, 90889, 199369, 810001, 8725201 are zeros).
* **F4 (prime zeros).** The 14 primes coprime to 105 with no solution: 409, 577, 5569, 9601, 23929, 83449, 102001,
  329617, 712321, 1134241, 1724209, 1726201, 5212561, 8813281 (all ≡ 1 mod 8). Any argument that is "uniform in n above
  an explicit bound" must have that bound > 8 813 281 — or must visibly fail at each of these.
