## 1. Precise statements attacked

* S a finite set of odd primes; for γ ∈ ∏_{ℓ∈S} ℤ_ℓ^× the profile e_{S,γ} ∈ Ẑ^× has component γ_ℓ at ℓ ∈ S and 1
  elsewhere. B_S := ∏_{ℓ∈S} NR_ℓ (non-residue units), with normalised Haar measure. U = profiles in no ET Prop 1.9
  family class (UCOVER §1). Survival s(S) := μ_{B_S}{γ : e_{S,γ} ∈ U}... more precisely the B_S-mass of profiles in
  no family class (or in no class of a given finite menu).
* An **event** at S is a family class catching some e_{S,γ}; its **level** N is the S-part of its modulus; it is
  **pure** if N is a power of one prime, **mixed** otherwise.
* **(D1)** Complete two-prime event reduction for all seven families (Theorem A, §2).
* **(D2)** Uniform count: every event of level N (any S, any family, any support split) is one of
  ≤ N^{4/5+O(1/log log N)} (Theorem E, from Lemma Q). Consequences: the two-prime mixed mass is
  ≤ (ℓ₁ℓ₂)^{−1/5+o(1)}; exact product law s = s₁^{pure}s₂^{pure} − Γ; no uniform multiplicative gain (Cor G);
  k-prime Theorem T and the obstruction k(y) ≥ y^{1/5−o(1)} for (PC) (Cor K).
* **(D3)** Bridge theorem: PC_F ⟹ MF(A) exactly when log F((log p)^A) < log p; PC_F is GRH-ES-strength as soon as
  log F(y) ≤ y^{1/A}, A > 2; the only non-ES regime is log F(y) ≥ y^{1/2−o(1)} (Theorem B, §4). ET classes have no
  integer-validity threshold (Lemma V, PROVED; `scripts/z68_pc2_validity.py`).
