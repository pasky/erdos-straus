# z52b free lane — `free_opus` (breadth-first connection list for Erdős–Straus)

**ES is OPEN.** Nothing here proves anything. This is a breadth-first list of candidate *connections*; the only filter
applied was "drop obvious nonsense / literal duplicates". Items were NOT screened against the barrier checklist.

**Method.** Unpigeonholed free association, organised loosely by source area (sections A–…). Each item has a concrete
first step. Literature stated as fact was spot-checked via the arXiv API; unverified leads are phrased as "check whether…"
in the first step. `seen:<file>` tags were added automatically by `git grep -i` of a distinctive keyword over the repo's
`*.md` (a hint that the theme was discussed before, not a claim that the exact item was).

Data: `data/z52b/free_opus.jsonl`. Built by `scripts/z52b_free_opus_build.py` from `scripts/z52b_free_opus_batch_*.py`.
