Comparison to Croot’s method.
     The main result of Croot [2] is actually a density statement for sets of P
                                                                              sufficiently
smooth numbers. Roughly speaking, Croot proves that if A ⊂ [2, N ] has n∈A n1 >
6 and all n ∈ A are ‘n1/4−o(1) -smooth’ (i.e. ifP a prime power q divides n ∈ A then
q ≤ n1/4−o(1) ) then A contains some S with n∈S n1 = 1. This suffices to deduce
the colouring statement of Theorem 1, but is too weak to deduce an unrestricted
density statement, since the set of n ∈ N which are not n1/4−o(1) smooth has
positive density.
