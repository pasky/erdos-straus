# Elsholtz–Tao (2013)

**Citation:** Christian Elsholtz and Terence Tao, “Counting the number of solutions to the Erdős–Straus equation on unit fractions,” *J. Aust. Math. Soc.* 94 (2013), 50–105. DOI: https://doi.org/10.1017/S1446788712000468. Preprint: https://arxiv.org/abs/1107.1010 ; PDF: https://terrytao.wordpress.com/wp-content/uploads/2011/07/egyptian-count13.pdf

**Verified quote** (Section 2, Type II parametrisation; exact searchable text in the published paper/preprint):

> “There exist a, b, c, d ∈ N such that 4abcd = na + nb + c with c coprime to n, and, since y = acd, it follows that ...”

The paper's Type II map gives the denominators (abd, acdn, bcdn), with the parameter equation equivalent to `c n + a + b = 4abcd` (variable naming/order varies between formulations). It studies/counts the general Type II family and gives further six-parameter parametrisations and Type II solvability criteria; I did not find a separately named b=1 subfamily or a claim that this line covers all primes 1 mod 4.

**Relevant quoted passage** (Section 11, “Generation of Type II solutions”):

> “In the m = 4, k = 3 case, Type II solutions were generated by the ansatz (t1, t2, t3) = (abd, acdn, bcdn) for various quadruples (a, b, c, d) (or equivalently, quadruples (a, c, d, e), setting b := ce − a); see (2.22).”
