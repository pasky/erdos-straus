H. W. Lenstra Jr., "Divisors in residue classes", Math. Comp. 42 (1984), no. 165, 331-340. doi:10.1090/S0025-5718-1984-0726007-1 (read from ams.org PDF)

Abstract: Let r, s and n be integers satisfying 0 <= r < s < n, s >= n^{1/3}, gcd(r,s)=1. Then there exist at most 11 positive divisors of n that are congruent to r modulo s. Moreover, there exists an efficient algorithm for determining all these divisors. ... It is not known whether 11 is best possible; in any case it cannot be replaced by 5. Nor is it known whether similar results are true for significantly smaller values of log s/log n.

Theorem (main, unnumbered). Let r,s,n be integers with 0<=r<s<n, s>=n^{1/3}, gcd(r,s)=1. Then there exist at most 11 positive divisors of n congruent to r mod s, and there is a polynomial algorithm (O((log n)^3) bit ops) for determining all these divisors.

(3.1) Proposition. For every real a > 1/4 there exists a constant c(a) such that: if r,s,n are integers with n>0, s >= n^a, gcd(r,s)=1, then the number of positive divisors of n congruent to r modulo s is at most c(a).
Remark (after 2.8): one can take c(a) = O((a-1/4)^{-2}) for 1/4 < a < 1. "I do not know whether the condition a > 1/4 in (3.1) can be replaced by a > 0."
Remark: gcd(r,s)=1 cannot be dropped (n^2, n odd, divisors = r mod s=n ... unbounded count).
Section 3: H. Cohen: infinitely many n with >= 6 divisors in one coprime class mod some s >= n^{1/3}.
Regime: SINGLE n, any n; UPPER bound only (no existence); modulus s >= n^{1/3} (resp. n^a, a>1/4).
