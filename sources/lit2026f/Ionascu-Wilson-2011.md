# Ionașcu–Wilson (2011): congruence exceptions are a different notion

**Citation:** Eugen J. Ionașcu and Andrew Wilson, “On the Erdős-Straus Conjecture,” *Rev. Roumaine Math. Pures Appl.* 56 (2011), no. 1, 21–30. PDF: https://csuepress.columbusstate.edu/cgi/viewcontent.cgi?article=1846&context=bibliography_faculty ; arXiv: https://arxiv.org/abs/1001.1100.

**Verified quotes** (§2 and §3):

> “The equation (1) has at least one solution for every prime number n, except possibly for those primes of the form n ≡ 1 (mod 24).” (§2, Proposition 2)

> “The residue 1201, the first prime in this list is not really an exception ... [an identity] shows that 9240 k + 1201 ∈ C8 ...” (§3)

> “Terzi [9] provides a list of 198 exceptional residues for the modulo 120120.” (§3)

**Relevance (inference):** These are modular sieve / restricted-small-denominator classes for the full equation, not a list of primes failing the b=1 Type II family. The paper's 193 and 2521 mentions and Terzi's residue exceptions must not be read as exceptions to the user's one-parameter slice.
