Theorem 1.1. sigma in {±1}, f in Z\{0}, max(-f,0) <= Y < X, X+f ≍ X; if sigma=-1 assume f > X. Then
  sum_{Y<n<=X} Lambda(n) tau(sigma n + f) = c_0(f)((X+sigma f)log(sigma X+f) - (Y+sigma f)log(sigma Y+f) + (2gamma-1)(X-Y)) + 2c_0'(f)(X-Y) + O_A(X(log X)^{-A});
  under GRH error O(X^{1-delta}).
 Covers Titchmarsh with long shifts (sigma=+1) and the DUAL problem (sigma=-1): sum_{p<X} tau(f-p) for a SINGLE fixed integer f>X — uniform in the shift.
Theorem 1.2. #{n = p + x^2 + y^2} = pi Li(n) prod_p(1+chi_{-4}(p)/(p(p-1))) prod_{p|n}(p-1)^2/(p^2-p+chi_{-4}(p)) + O_A(n(log n)^{-A}).
Theorem 1.3. cusp form phi: sum_{Y<n<=X} Lambda(n) lambda(sigma n+f) << X^{1-delta}, uniformly in f.
Mechanism: Bombieri–Vinogradov-range + Kloosterman/spectral (Deshouillers–Iwaniec with explicit shift dependence) for uniformity in f; no parity breaking needed (divisor function is Type-I-friendly).
Relevance: genuinely "at a single integer f": averages over primes p<f, NOT a statement about a single prime.
