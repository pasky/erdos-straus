J. Borwein, K.-K. S. Choi, "On the representations of xy+yz+zx", Experimental Math. 9 (2000), no. 1, 153–158. (read via http://plouffe.fr/OEIS/citations/borchoi.pdf; not on arXiv)
Thm 1.1: There are at most 19 integers that are not of the form xy+yz+xz with x,y,z >= 1. The only such non-squarefree integers are 4 and 18. The first 16 squarefree ones are 1,2,6,10,22,30,42,58,70,78,102,130,190,210,330,462. If the 19th integer exists, it must be greater than 10^11. Moreover, assuming GRH, the 19th integer does not exist and the list is complete.
  ("in fact, we only need to assume the Siegel zero doesn't exist" — exception = Weinberger 1973 possible exceptional disjoint discriminant, from a Siegel zero of L(s,(-d/.)).)
Thm 2.6: 4 and 18 are the only non-squarefree non-representable N (OEIS A025052 gives an explicit elementary construction for N with a square factor).
Thm 3.1: Let N = 2 p1...pr (distinct odd primes). Then N is not representable iff -4N is a disjoint discriminant (each genus contains exactly one reduced form, i.e. h(-4N) = 2^r = #genera; = idoneal/Euler "numeri idonei" type condition).
  Proof mechanism: Crandall/Andrews theta identity (3–1): (-1)^N r3(N) = -6 sum_{xy=N}(-1)^{x+y} - 4 sum_{xy+xz+yz=N}(-1)^{x+y+z}; for N≡2 mod 4: r3(N) = 6d(N)+4 r_t(N) = 12·2^r + 4 r_t(N); Gauss r3(N)=12 h(-4N); so r_t(N)=0 iff h(-4N)=2^r. Then Chowla/Weinberger finiteness of disjoint discriminants (ineffective except one possible Siegel-zero exception).
  Odd squarefree N: handled elementarily (N≡1,3 mod 4 cases, sec. 2).
Thm 3.2 (Zhu–Shao 1988 Thm 4): squarefree N is representable iff there is an odd prime p < [bound garbled in pdftotext: "43 N", probably (4/3)sqrt(N)] such that -N is a quadratic residue mod p.
RELEVANCE: pointwise all-but-finitely-many result for a ternary "xy+yz+zx" problem, via an EXACT class-number formula for the representation count (r3 = 12h), not via sieve/averaging. Exception set controlled by Siegel zero (one possible exception unconditionally).
