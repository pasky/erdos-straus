# Provenance: Jacobsthal literature for §58

Fetched 2026-08-30 for the §58 literature audit.

- `costello-watts-2013.pdf` — Fintan Costello and Paul Watts, *A short note on Jacobsthal's function*, arXiv:1306.1064v1 (2013). Downloaded from <https://arxiv.org/pdf/1306.1064>. SHA-256 `04fe7b680a3eaccf4153f636c02bf572f449ff386914f38beb4d87ad9ab91ef9`. Page 1 defines `g(n)` as the least length forcing an integer coprime to `n` in every interval and explicitly calls `g(n) <= X (k log k)^2`, `k = omega(n)`, Iwaniec's best **asymptotic** upper bound, for an absolute but unspecified constant `X`. This is the exact secondary-source statement; §58 restricts the literal `(k log k)^2` form to `k >= 2` (or uses `k log(2k)` for all `k`) because the displayed expression vanishes at `k = 1`.
- `ford-green-konyagin-maynard-tao-2014.pdf` — Kevin Ford, Ben Green, Sergei Konyagin, James Maynard, and Terence Tao, *Long gaps between primes*, arXiv:1412.5029 (downloaded from <https://arxiv.org/pdf/1412.5029>). SHA-256 `6a2c86f06946315f2abafb11b25c60bef9ca780921e4b0c1f55a144430c48145`. Pages 2–3 define `j(n)` as the maximal gap between integers coprime to `n`, identify `Y(x)=j(P(x))-1`, and state that Iwaniec's work gives `Y(x) << x^2`; this is an endpoint-shifted primorial consequence, not a second verification of the full general bound. The paper's results are lower bounds for maximal gaps.
- `ford-konyagin-maynard-pomerance-tao-sieved-sets.pdf` — Kevin Ford, Sergei Konyagin, James Maynard, Carl Pomerance, and Terence Tao, *Long gaps in sieved sets* (2018 preprint). Downloaded from <https://math.dartmouth.edu/~carlp/longgaps.pdf>. SHA-256 `c5d8df94544bbe0ce34fe9b4fef1549082acec194ec8822f88d228608b6f04f5`. Definition 1 and Theorem 1 treat a bounded set of residue classes at each prime and prove large gaps in a one-dimensional sifted set; they do not give an upper bound for the first survivor of a system involving composite moduli.

Primary-source retrieval note: Iwaniec's *On the problem of Jacobsthal*, Demonstratio Mathematica 11 (1978), 225–231, DOI <https://doi.org/10.1515/dema-1978-0121>, is marked open access by the publisher. Direct PDF and legacy-PDF requests on 2026-08-30 were redirected to De Gruyter Brill's automated human-verification page and returned no PDF bytes. No fake primary copy is archived here. The bound used in §58 is therefore **secondary-source-verified only** in the accessible full Costello–Watts paper; its primorial specialization was independently checked in the accessible full Ford–Green–Konyagin–Maynard–Tao paper. Nothing in §58 or this archive claims inspection of Iwaniec's primary text.
