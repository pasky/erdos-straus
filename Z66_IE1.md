**Results in one paragraph.**
* **Thm L (PROVED).** Characterises when *odd-square component landing* (the square-landing arcs of U64/L65,
  generalised to semialgebraic components) gives a counter-model for a theory T ⊇ IOpen: exactly when T proves no
  finite disjunction of "arc certificates" at the large primes of the class. An arc certificate is an existential
  statement whose real solution set is open and closed in the real zero set of its own equations over {n > 0}, and
  contains no integer point with n an odd square. The (★) equation with u, B, C > 0 is one. Clopenness is essential:
  "s² < n < (s + 1)²" has no integer point at squares but is not clopen, and IOpen proves it.
* **Thm K (PROVED).** The floor of √n together with Lagrange's four-square theorem (or the weaker true Π₁ principle
  P₄: "every x ≥ 1 divides some 1 + z₁² + ⋯ + z₄²") gives an arc certificate at every non-square.
  * So odd-square component landing cannot prove T ⊬ (MS) for any T ⊇ IOpen + Lag. By results in the literature
    this covers IΔ₀ + Count₂(Δ₀), IΔ₀ + iWPHP(Δ₀), IΔ₀ + Ω₁ and IΔ₀ + exp. Other mechanisms, such as L65 Thm D's
    polynomial non-solvability along progressions, are not covered.
  * Conversely, an OSCL counter-model for IΔ₀ would show IΔ₀ ⊬ P₄. Our search found no natural unrelativized Π₁
    sentence known to be independent of IΔ₀ (Assessment).
  * This corrects L65's Assessment that the Lagrange obstacle is "plausibly an artefact of the polynomial
    realisation".
* **Thm G (PROVED, relative to Wilmers' theorem as quoted by D'Aquino 1997).** No nonstandard model
  of IE₁ admits a ring homomorphism to ℤ. So the "4 > 3" global landing (Shepherdson's model; U64's M_{q*=1}) is
  unavailable for IE₁.
* **Thm E (PROVED).** M_E = ℤ + xℚ[x] is a model of discretely-ordered-ring axioms + Bezout + IOpenLin + PB + PD +
  Th_∀(ℤ) + T1, in which n = x + 1 is a prime ≡ 1 (mod every standard k ≥ 1) with ¬ES(n), ¬ES★(n). By U64, NOI ⊬ (MS)
  as well, and IOpen = IOpenLin + eIOpen (Glivická–Glivický Cor 6). So IOpen ⊬ (MS) and IOpenLin + Bez ⊬ (MS) are both
  established. Assessment: on this ladder IOpen + Bez is the first open combination (eIOpen + Bez is not settled
  either).
* **Q2 (PROVED from literature).** IΔ₀ + exp does not prove all true Π₁ sentences: Con(Q) is a true ∀Δ₀ sentence it
  does not prove (Hájek–Pudlák Cor V.5.29), and the matrix of every Π₁ sentence is bounded. Wilkie's theorem
  (HP V.5.26) gives the exact description.

## 3. Odd-square component landing, exactly (Thm L)

Let M ⊨ IOpen, n ∈ M with n > 0, and let A = ℤ[n, ȳ] ⊆ M be finitely generated (ȳ = (y₁..y_k)). Let I ⊆ ℤ[t, Ȳ] be
the ideal of all polynomial relations among (n, ȳ) in M, and P = (P₁..P_s) a finite generating set (Hilbert). Put
W_A := {(t, ȳ) ∈ ℝ^{1+k} : P = 0, t > 0}. These are the real points of Spec A with n > 0.

**Facts used (standard real algebraic geometry; Bochnak–Coste–Roy, *Real Algebraic Geometry*, Thm 2.4.4 and §5.3;
not re-verified here).**
* A semialgebraic set has finitely many connected components, each semialgebraic.
* For a set defined over ℚ, the components are defined over ℝ_alg, and they correspond to the semialgebraically
  connected components over any real closed field R ⊇ ℝ_alg.
* Every element of ℝ_alg is ∅-definable in the ordered field ℝ_alg, so by quantifier elimination each component C is
  defined by a quantifier-free formula χ_C(t, ȳ) with integer coefficients.
* Tarski transfer between ℝ_alg, ℝ and the real closure R(M) applies to all ∅-definable statements below.

**Definition 3.1.**
* The *tautological point* (n, ȳ) ∈ W_A(R(M)) lies in exactly one component C_A, i.e. R(M) ⊨ χ_{C_A}(n, ȳ). This holds
  because W = ⊔ C_i is an ∅-definable statement true in ℝ_alg, hence in R(M).
* Let r, q be standard integers, q ≥ 1. n is an **arc point for the class r mod q** if n > 0, n ≡ r (mod q) in M, and
  for every finitely generated A ∋ n, (n − r)/q, the component C_A contains a point of ℤ^{1+k} whose t-coordinate is
  an odd square. (Without the congruence the condition would be vacuous off the class.) Ring homomorphisms are unital;
  an integer point of W_A is the same as a ring homomorphism A → ℤ with n ↦ t > 0. The notion does not depend on the
  choice of generators.
* An **arc certificate** is a formula ψ(t, ȳ) ≡ (⋀_i P_i(t, ȳ) = 0 ∧ χ(t, ȳ)), with P_i ∈ ℤ[t, Ȳ] and χ quantifier-free
  with integer coefficients, such that:
  * S_ψ := {t > 0, P = 0, χ} ⊆ ℝ^{1+k} is open and closed in {t > 0, P = 0};
  * S_ψ contains no integer point with t an odd square.

U64's analytic arcs (U64 Lemma 2.3, Prop 6.2) produce arc points. The arc starts at the integer landing point and stays
in W_A. For large s it satisfies every atom of χ_{C_A}, since these are sign conditions on elements of A, and the arc gives
them their M-sign (U64 Lemma 2.3(b)), which is also their sign at the tautological point. So the arc ends in C_A, and the landing point is in C_A.

**Lemma 3.2 (arc points refute (★); PROVED).** If n is an arc point, then M ⊨ ¬ES★(n).
*Proof.*
* Let u, B, C ∈ M be ≥ 1 with 4uBC − u − B = n, and add them to the generators of A.
* On W_A the relation 4uBC − u − B = t holds, so S := {u, B, C > 0} ∩ W_A is open, and it is closed in W_A by
  positive closedness of Σ★ over t > 0 (L65 Lemma 2.2(a)).
* So S is a union of components. The tautological point lies in S(R(M)) ∩ C_A(R(M)). Hence C_A ∩ S ≠ ∅ (transfer
  to ℝ), so C_A ⊆ S.
* The integer point of C_A with t = m², m odd, then has u, B, C positive integers with 4uBC − u − B = m². This
  contradicts R(m²) = 0 (T1; Z57_SYNTH Lemma A.1(b)). ∎

The (★) system with u, B, C > 0 is itself an arc certificate. The same holds for the Type I/II systems of U64 Prop 6.2,
which are positively closed and, by ET Prop 1.6 with the Type II descent, have no odd-square integer points. So in GCD
models an arc point n that is prime also has ¬ES(n).

**Theorem L (characterisation of odd-square component landing; PROVED, relative to the facts above).** Let T ⊇ IOpen and let r mod q
be a class. The following are equivalent:
* (a) some M ⊨ T contains a nonstandard prime n ≡ r (mod q) that is an arc point;
* (b) for every N ∈ ℕ and every finite list of arc certificates ψ₁..ψ_J,
  T ⊬ ∀n (Prime(n) ∧ Cl_{r,q}(n) ∧ n > N → ⋁_j ∃ȳ ψ_j(n, ȳ)).

In case (a), M ⊨ T + ¬ES★(n) (Lemma 3.2), so T ⊬ ES★_prime[r mod q]. Arc points can only exist in classes that
contain odd squares, since the landing value t = m² satisfies t ≡ r (mod q). For r = 1, q = 840 (and n > 10¹⁷, as n is
nonstandard), case (a) gives T ⊬ (MS).

*Proof.*
* (a) ⇒ (b). Suppose M ⊨ ψ_j(n, ȳ) for some j, and let A = ℤ[n, ȳ, (n − r)/q].
  * The relations of A include P_j, so W_A ⊆ {t > 0, P_j = 0} (forgetting the extra coordinate).
  * S_{ψ_j} ∩ W_A is clopen in W_A and contains the tautological point. So, as in Lemma 3.2, it contains C_A.
  * Hence C_A has no odd-square integer point, and n is not an arc point.
* (b) ⇒ (a). Let c be a new constant and Γ := T ∪ {Prime(c), Cl_{r,q}(c)} ∪ {c > N : N ∈ ℕ} ∪ {¬∃ȳ ψ(c, ȳ) : ψ an arc
  certificate}.
  * A finite subset of Γ involves finitely many ψ_j and one N. If it were inconsistent, T would prove the displayed
    disjunction. So Γ is consistent, by (b) and compactness.
  * Take M ⊨ Γ and a finitely generated A ∋ c, (c − r)/q, with relations P and component C_A.
  * Put ψ := (P = 0 ∧ χ_{C_A}). Then S_ψ = C_A is clopen in W_A, and M ⊨ ψ(c, ȳ).
  * If C_A had no odd-square integer point, ψ would be an arc certificate, which contradicts Γ. So c is an arc point. ∎

*Readings.*
* Call the method of Lemma 3.2 **odd-square component landing** (OSCL). It contains every square-landing arc
  construction of U64 and L65 (U64 Thms A, A′, A″, L65 Thm T, and NOI ⊬ (MS) at q* = 1). OSCL proves
  T ⊬ ES★_prime[r mod q] exactly when T proves no finite disjunction of arc certificates at the large primes of the
  class. To show that OSCL fails for T, one T-provable certificate is enough.
* Because the (★) system is itself a certificate, OSCL is "complete relative to its own certificate class". It
  succeeds only for theories that prove no existential non-squareness statement of this robust (clopen) kind.
* Scope. Thm L concerns OSCL only. It does not cover L65's other mechanism (Prop 5.5 / Thm D: polynomial
  non-solvability along a whole progression of landing points), nor any technique that does not land at integer points.
  It needs no analyticity and produces its models by compactness, not explicitly.

## 4. Theorem K: Lagrange (or P₄) kills odd-square landing

**Theorem K (PROVED).** Let M ⊨ IOpen + P_k for some k ≥ 1 (the relevant case is k = 4: P₄ is true in ℕ and follows
from Lag). Then no nonstandard non-square element of M is an arc point, for any class containing it. Equivalently: for
T ⊇ IOpen + P_k, the formula below is a T-provable arc certificate at every non-square n > 1. Hence T has no OSCL
counter-models, and **OSCL cannot show T ⊬ ES★_prime[r mod q] or T ⊬ (MS)**, whatever the class.

*The certificate.* Write z̄, z̄′ for k-tuples and put
> ψ_K(t; s, w₁, w₂, y₁, y₂, z̄, z̄′) :≡ t = s² + w₁ ∧ (s + 1)² = t + w₂ ∧ w₁y₁ = 1 + Σz_i² ∧ w₂y₂ = 1 + Σz′_i² ∧ w₁ > 0 ∧ w₂ > 0.

*Proof.*
* *T proves ∃ ψ_K at non-squares.* IOpen gives s = ⌊√n⌋, i.e. s² ≤ n < (s + 1)² (Shepherdson). If n is not a square,
  then w₁ := n − s² ≥ 1 and w₂ := (s + 1)² − n ≥ 1, and P_k supplies y₁, z̄, y₂, z̄′. A nonstandard prime is not a
  square.
* *ψ_K is an arc certificate.*
  * On the variety {equations of ψ_K, t > 0}, w₁y₁ = 1 + Σz_i² ≥ 1, so w₁ never vanishes; likewise w₂. Hence
    {w₁ > 0, w₂ > 0} is open and closed in it.
  * At an integer point, w₁, w₂ ≥ 1 give s² < t < (s + 1)², so t is not a square, odd or even.
* Now apply Thm L, (a) ⇒ (b). ∎

**Corollary K.1 (PROVED relative to the cited results).** OSCL gives no counter-model, at any class, for:
* IΔ₀ + Count₂(Δ₀) (Lag; Jeřábek MLQ 2010, remark after Thm 5.7, VERIFIED);
* IΔ₀ + iWPHP(Δ₀) (Lag; Berarducci–Intrigila 1991, as reported by Jeřábek and by the Dimitracopoulos survey, Thm 11);
* IΔ₀ + Ω₁ (Δ₀-WPHP, Paris–Wilkie–Woods as quoted by Bovenzi–D'Aquino; their form excludes injections from (1 + ε)z
  into z, and ε = 1 gives the injective form iWPHP used by Berarducci–Intrigila);
* IΔ₀ + exp (⊢ Ω₁).

Note the scope: this kills OSCL, not unprovability. These theories might still fail to prove ES. A counter-model would
then not be an OSCL counter-example: it would need a different mechanism (e.g. a Thm D-type progression argument, if
one could be made compatible with Lag, or something not landing at integer points at all).

**Corollary K.2 (barrier for IE₁ and IΔ₀; PROVED).** If T ⊇ IOpen has an OSCL counter-model at some class (in
particular, if the U64/L65 square-landing method is ever extended to T), then T ⊬ P_k for every k, and T ⊬ Lag.
* For T = IΔ₀ this would give a natural true Π₁ sentence (P₄; its matrix is bounded) unprovable in IΔ₀.
  * Assessment: our search found no natural unrelativized Π₁ independence of this kind for IΔ₀.
  * The standard open problems listed in the survey are of different shapes: unboundedness of primes is Π₂, Δ₀-PHP and
    MRDP are schemes. The bounded prime-existence candidate is Bertrand's postulate (Π₁, provable in IΔ₀ + Ω₁, open
    for IΔ₀; HP pp. 392–393). "It is widely believed that the answer to all these problems is 'no'" (survey).
* For T = IE₁, our search found no Π₁ independence result for a concrete number-theoretic statement either (Π₂ ones,
  such as Pell, follow from D'Aquino's equivalence; lit_ie1.md §8).

## 5. Global landing (Thm G)

"Global landing" means a single ring homomorphism e: M → ℤ together with a path to the order at infinity. Examples are
Shepherdson's model, U64's M_{q*=1} (where NOI ⊬ (MS) is "4 > 3", L65 §2), and Thm E below.

**Lemma G1 (PROVED, elementary).** Let M be a discretely ordered ring with division with remainder by numerals (e.g.
M ⊨ IOpen), and let e: M → ℤ be a ring homomorphism.
* (a) x ≡ e(x) (mod k) in M for all x ∈ M and k ≥ 1.
* (b) D := ker e = ⋂_k kM. D is a ℚ-vector space and M = ℤ ⊕ D. If M is nonstandard, D ≠ 0, and every nonzero
  element of D is nonstandard.
* (c) If M ⊨ Bez, no two nonzero elements of D are coprime.

*Proof.*
* (a) Write x = kq + ρ with 0 ≤ ρ < k; ρ is a numeral. Then e(x) = k·e(q) + ρ, so x − e(x) = k(q − e(q)) ∈ kM.
* (b) If e(x) = 0 then x ∈ kM for all k by (a). Conversely, x ∈ ⋂ kM gives e(x) ∈ ⋂ kℤ = 0.
  * If x = ky with x ∈ D, then k·e(y) = 0, so y ∈ D.
  * x = e(x) + (x − e(x)) gives M = ℤ ⊕ D. A nonstandard x gives x − e(x) ≠ 0 in D.
  * |d| ≥ 1 for d ∈ D∖0, and d is not an integer, so d is nonstandard.
* (c) A Bezout gcd d = ua + vb of a, b ∈ D lies in D, so it is not a unit. ∎

**Theorem G (PROVED, relative to Wilmers' and McAloon's theorems that every nonstandard model of IE₁ (resp. IΔ₀) has a
nonstandard initial segment satisfying PA, as quoted verbatim by D'Aquino, NDJFL 1997 — VERIFIED quote; the original
theorem statements were not accessible).** No nonstandard model of IE₁, and hence none of IΔ₀ or PA, admits a ring
homomorphism to ℤ.
*Proof.*
* Let M ⊨ IE₁ be nonstandard, let e: M → ℤ, and let I ⊆ M_{≥0} be a nonstandard initial segment with I ⊨ PA. Then
  R := I ∪ (−I) is a subring of M: |a − b| ≤ max(a, b), and I is closed under + and ·. R ⊨ PA in the ring sense, and
  e|_R is a ring homomorphism.
* Take a nonstandard x ∈ I. By Lemma G1(b) for R, a := |x − e(x)| ∈ D_R := ker(e|_R) is positive and nonstandard.
* In PA (indeed IΔ₀), a = t·z with Pow(2, t) or t = 1, and z odd. Here Pow(2, t) means that every divisor > 1 of t is
  even; take t the largest such divisor of a and use Euclid's lemma. Likewise a = t′z′ with Pow(3, t′) or t′ = 1, and
  3 ∤ z′.
* e(z) is odd by G1(a), and e(t)e(z) = e(a) = 0, so e(t) = 0. Similarly e(t′) = 0. Then t, t′ ≠ 1, so t, t′ ∈ D_R∖0.
* gcd(t, t′) = 1: a common divisor d > 1 is even (it divides t), so 2 | t′, so 3 | 2.
* This contradicts G1(c) for R, since R ⊨ Bez. ∎

(Smith's NDJFL paper notes that in IE₁ every odd m > 1 is ab + 1 with a odd and Pow(2, b), from Smith 1992. That gives
a direct route without Wilmers, if the 3-power splitting is also available; not checked.)

**Corollary G.1 (PROVED).** Let M be a discretely ordered ring with an element exceeding every numeral (IOpen is not
needed).
* (a) If M ⊨ Lag, M has no ring homomorphism e to ℝ. Indeed x ≥ 0 ⇒ x = Σ squares ⇒ e(x) ≥ 0, so e is monotone, and
  e(n) ≥ N for every numeral N when n is nonstandard.
* (b) If M ⊨ P_k for some k, M has no ring homomorphism e to ℤ. Take n nonstandard positive and N := e(n) ∈ ℤ. Then
  w := n − N ≥ 1 in M, and P_k gives wy = 1 + Σz_i², so e(w)e(y) ≥ 1. But e(w) = 0.

*Reading.* Global landing, the simplest mechanism of all, exists in OI models (Shepherdson, U64 M_{q*=1}) and in
Bezout + IOpenLin models (Thm E). It is impossible in IE₁ (Thm G) and in IOpen + Lag (G.1). IE₁ counter-models via arcs,
if any, must land at points that vary with the finitely generated subring, as in U64's general Thm A.

## 6. Theorem E: Bezout without root floors does not prove (MS)

Let M_E := ℤ + xℚ[x] = {f ∈ ℚ[x] : f(0) ∈ ℤ}, ordered by the sign of the leading coefficient (x is positive and
larger than every integer).

**Theorem E (PROVED, elementary).** M_E is a discretely ordered ring with the following properties:
* (i) Bezout, hence GCD and integrally closed;
* (ii) an integer part of its fraction field ℚ(x), hence M_E⁺ ⊨ IOpenLin (Glivická–Glivický Thm 3);
* (iii) PB: R/pR is a field for every prime p;
* (iv) PD: every element ≥ 2 has an irreducible divisor;
* (v) Th_∀(ℤ) (ring language);
* (vi) every positively closed ℕ-non-existence fact, in particular T1★ and T1_II.

For every irreducible f ∈ ℚ[x] with f(0) = 1, positive leading coefficient and f(s) > 0 on [0, ∞) (e.g. x + 1,
x² + 1, 840x + 1, x^{2^j} + 1), n := f is a nonstandard prime of M_E with n ≡ 1 (mod k) for every k ≥ 1, and
M_E ⊨ ¬ES(n) ∧ ¬ES★(n). Hence
> **DOR + Bez + IOpenLin + PB + PD + Th_∀(ℤ) + T1★ + T1_II ⊬ ES_prime[1 mod q] for every q, and ⊬ (MS);**
and the counterexample primes are cofinal (x^{2^j} + 1).

*Proof.* Write R = M_E.
* *Order and discreteness.* R ⊆ ℚ[x] is an ordered subring. A nonconstant f has |f| > every integer, so 0 < f < 1
  forces f constant, hence f ∈ ℤ, which is impossible.
* *(i) Bezout.* Let f, g ∈ R, not both 0 (if one is 0 the ideal is principal).
  * Let h := gcd_{ℚ[x]}(f, g), normalised as h = x^j h₀ with h₀(0) = 1. Write f = hf′ and g = hg′ with f′, g′ coprime
    in ℚ[x], and put α := f′(0), β := g′(0) ∈ ℚ. Not both are 0, since x ∤ gcd(f′, g′).
  * If j = 0 then α = f(0), β = g(0) ∈ ℤ. If j ≥ 1, α and β are only rational.
  * In both cases let γ ∈ ℚ_{>0} generate the ℤ-module αℤ + βℤ, and choose a₀, b₀ ∈ ℤ with a₀α + b₀β = γ.
  * *Claim: (f, g) = (γh) as ideals of R.*
    * γh ∈ R: if j ≥ 1, (γh)(0) = 0; if j = 0, (γh)(0) = γ ∈ ℤ, as γ is the integer gcd(α, β).
    * f = γh·(f′/γ), with (f′/γ)(0) = α/γ ∈ ℤ, so f′/γ ∈ R. Likewise for g.
    * Conversely, φ := γ − a₀f′ − b₀g′ has φ(0) = 0, so φ = xφ₁. Since f′, g′ are coprime in the PID ℚ[x], there are
      r₁, s₁ ∈ ℚ[x] with r₁f′ + s₁g′ = φ₁.
    * Then (a₀ + xr₁)f + (b₀ + xs₁)g = h(a₀f′ + b₀g′ + φ) = γh, with coefficients a₀ + xr₁, b₀ + xs₁ ∈ R.
  * Bezout domains are GCD domains and integrally closed.
* *(ii) Integer part of ℚ(x).* Let r ∈ ℚ(x). Write r = q + ε with q ∈ ℚ[x] and ε a proper fraction, so ε is 0 or
  infinitesimal. Let q₀ := q(0).
  * If q₀ ∉ ℤ, or ε ≥ 0: m := q − q₀ + ⌊q₀⌋ ∈ R and r − m = (q₀ − ⌊q₀⌋) + ε ∈ [0, 1).
  * If q₀ ∈ ℤ and ε < 0: m := q − 1 ∈ R and r − m = 1 + ε ∈ (0, 1).
* *(iii) PB, and the primes of R.* Units of R are ±1 (a unit is a constant c with c, 1/c ∈ ℤ). Let p ∈ R be
  irreducible.
  * If p is constant, p = ±ℓ for a standard prime ℓ. Every element of xℚ[x] lies in ℓR, so R/ℓR ≅ ℤ/ℓ.
  * If p is nonconstant:
    * p(0) ∉ {0} ∪ {a : |a| ≥ 2}. Otherwise p = 2·(p/2), resp. p = a·(p/a), is a nontrivial factorisation in R. So
      p(0) = ±1.
    * p is irreducible in ℚ[x]. Otherwise p = gh with g(0) = 1, h(0) = p(0), both in R.
    * The map R/pR → ℚ[x]/(p) is injective: if p | f in ℚ[x], then f/p has constant term ±f(0) ∈ ℤ, so f/p ∈ R.
    * It is surjective: q + pc with the constant c := ∓q(0) lies in R.
    * So R/pR ≅ ℚ[x]/(p) is a field.
  * Conversely, an irreducible f ∈ ℚ[x] with f(0) = 1 is irreducible in R: a factorisation in R has a constant factor
    c ∈ ℤ with 1/c ∈ ℤ.
  * f ≡ 1 (mod k): (f − 1)/k ∈ xℚ[x] ⊆ R.
* *(iv) PD.* Let f ≥ 2.
  * If |f(0)| ≥ 2, a standard prime ℓ | f(0) divides f.
  * If f(0) = 0, then 2 | f.
  * If f(0) = ±1, an irreducible factor g of f in ℚ[x], normalised with g(0) = 1, lies in R and divides f in R.
* *(v) Th_∀(ℤ).* As in U64 Thm A″. Finitely many elements of R lie in ℚ[x] with a common denominator D, and finitely
  many nonzero polynomials have a common non-root s ∈ Dℤ (avoid the roots of their product), so none of them vanishes there. The evaluation x ↦ s maps them to ℤ and preserves every
  atom.
* *(vi) Positively closed facts.* As in L65 Thm P, with the path s ↦ ev_s for s ∈ [s₀, ∞), s₀ ∈ Dℤ_{≥0}, landing at s₀.
* *¬ES★(n).* Suppose u, B, C ∈ R are ≥ 1 with 4uBC − u − B = n.
  * The evaluations ev_s: R → ℝ (s ∈ [0, ∞)) are ring homomorphisms, continuous in s, with ev₀(R) ⊆ ℤ. For large s,
    ev_s(g) has the R-sign of g.
  * n(s) > 0 on [0, ∞). L65 Lemma 2.1, with Σ★ positively closed over σ ≥ 0, gives u(s), B(s), C(s) > 0 for all s ≥ 0.
  * So u(0), B(0), C(0) are positive integers with 4uBC − u − B = n(0) = 1. But for positive integers
    4uBC − u − B ≥ u(2B − 1) + B(2u − 1) ≥ 2.
* *¬ES(n).* By U64 Lemma 2.4 (polynomials are analytic), x(0), y(0), z(0) would be positive integers with
  4 = 1/x(0) + 1/y(0) + 1/z(0) ≤ 3. ∎

*What M_E does not satisfy.*
* eIOpen fails: ℚ(x) is not dense in its real closure (√x cannot be approximated to within x^{−5}: a rational function
  r with |r − √x| < x^{−5} would have an expansion in half-integral powers). ⌊√x⌋ does not exist.
* TS fails (x + 1 is not a sum of two squares, by degree), as do Lag and every P_k
  (Cor G.1(b), which needs only a discretely ordered ring; directly: xy = 1 + Σz_i² is impossible at x = 0), and E(−1)
  at n (R/nR ≅ ℚ).
* So Thm E is the "linear half" of IOpen: Euclidean division by non-standard elements and Bezout identities, with no
  root floors.

**Reading (Assessment, with one PROVED structural fact).** U64 shows NOI ⊬ (MS), and NOI ⊇ IOpen ⊇ eIOpen. Thm E shows
IOpenLin + Bez ⊬ (MS). Since IOpen = IOpenLin + eIOpen, the first open combination is **IOpen + Bez**.
* PROVED (G1): a global-landing model of IOpen + Bez has the D + M form M = ℤ ⊕ D.
* PROVED: since Bezout localisations are valuation rings, M_D is a valuation ring with residue field ℚ.
* Assessment: the natural 1-dimensional towers B = ⋃ ℚ[C_N ∖ S_N] (affine curves with one place at infinity, Picard
  classes dying in the tower) cannot be dense in their real closure. Genus 0 forbids growing both the value group and
  the residue field at infinity (Riemann–Hurwitz). Genus > 0 breaks IOpenLin, through the H¹(C, O) obstruction to
  matching polar parts. So a global-landing IOpen + Bez model, if it exists, is not of this simple kind. (Sketch only;
  not claimed as a theorem.)

## 7. Q2 and the IΔ₀ / IΔ₀ + exp barrier statements

* **Q2 (PROVED from HP).** "IΔ₀ + exp proves every true Π₁ sentence with polynomially bounded witnesses" is false.
  * Every Π₁ sentence is ∀Δ₀: its matrix is bounded, so "polynomially bounded witnesses" is no restriction on the
    class. Con(Q) is a true ∀Δ₀ sentence and IΔ₀ + exp ⊬ Con(Q) (HP Cor V.5.29).
  * Relying in addition on formalised MRDP in IΔ₀ + exp (Gaifman–Dimitracopoulos; Thm 4 of the Dimitracopoulos survey,
    VERIFIED in the OCR), Con(Q) is IΔ₀ + exp-equivalent to a sentence ∀x̄ (P(x̄) ≠ 0). In ℕ-form this reads
    ∀x̄ ∃w ≤ P⁺ + P⁻ ((P⁺ − P⁻ − w − 1)(P⁻ − P⁺ − w − 1) = 0), a bounded-existential Diophantine type of the same kind
    as ES (∀n ∃x, y, z ≤ 2n⁴: polynomial equation), though not the special ES equation.
  * So no syntactic criterion of this kind helps. The exact Π₁ content of IΔ₀ + exp is Wilkie's theorem (HP V.5.26):
    the bounded φ such that Q ⊢ ∀x (I(x) → φ(x)) for some Q-definable cut I.
  * The relevant *heuristic* is Friedman's conjecture (VERIFIED quote, §2): any ES proof of ordinary kind is expected
    to formalise in EFA = IΔ₀ + exp. It is a conjecture, not a theorem.
* **If ES is true, what an EFA counter-model would require (Assessment, made precise by Thm K).** (Unprovability as
  such does not require truth: a standard counterexample would also make ES unprovable. The interesting case is the
  conditional one.)
  * A model of IΔ₀ + exp in which the existential sentence "there is an ES counterexample" holds. If ES is true, that
    sentence is a false Σ₁ sentence.
  * For a counterexample n at a nonstandard prime of the Mordell class, by Thm K, n is not an OSCL counter-example.
    Whatever obstruction the model has at n is not the odd-square component landing of U64/L65.
  * Known independence results for IΔ₀ + exp concern consistency-type sentences (Con(Q), HP V.5.29). We know of no
    mechanism connecting ES to them. This is the U64 §4 conclusion, now extended down to IΔ₀ + Count₂(Δ₀).
* **IΔ₀ alone.**
  * If IΔ₀ + Ω₁ ⊢ ES_prime[1 mod 840] (e.g. via an elementary proof that uses only polynomial-size counting), a proof
    of IΔ₀ ⊬ ES_prime[1 mod 840] would show that IΔ₀ + Ω₁ is not Π₁-conservative over IΔ₀. That is open, and HP
    say that it "appears to be" related to open problems in complexity theory (e.g. PH vs LinH), while proving no such
    relation.
  * Independently of that, an OSCL proof would give IΔ₀ ⊬ P₄ (Cor K.2).
  * Either way, IΔ₀ ⊬ ES is beyond current technique (Assessment).

## 8. IE₁ and IΔ₀: what is known, what a counter-model must look like

* **Known IE₁ arithmetic at a nonstandard prime n** (Smith 1993, VERIFIED): M/nM is a field (Cor 2.8, so PB); QR
  against standard primes in one direction (Thm 3.11: ℓ a square mod n ⇒ n a square mod ℓ, for standard ℓ, up to the

  for IΔ₀ + Count₂(Δ₀), IΔ₀ + Ω₁ and IΔ₀ + exp. For IE₁ and IΔ₀ it could only work after proving a natural Π₁
  independence (P₄ or Lagrange) of a kind we found no instance of, and without a global landing point (Thm G).
* On the constructive side, Bezout identities plus Euclidean division do not prove (MS) (M_E). IOpen + Bez is the
  first open combination.
* For the campaign, any formal proof of ES on a square class must use principles that defeat odd-square landing.
  Order-to-algebra principles such as Lagrange already do this, so above IΔ₀ + Count₂ the known logic gives neither a
  further obstruction nor a further hint (Assessment): the remaining wall is B2.
