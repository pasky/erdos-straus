## 1. Precise statements attacked (checkpoint 1)

Notation as in U64 §1 / L65 §1: ES(n), ES★(n), Prime(n), ES_prime[r mod q]; (MS) = ES★ (Hit form) at all primes
n > 10¹⁷ with n mod 840 ∈ 𝔐 = {1, 121, 169, 289, 361, 529}.

* **Q1 (brief).** For T ∈ {IE₁, IΔ₀, IΔ₀ + Count₂(Δ₀), IΔ₀ + Ω₁, IΔ₀ + exp}: T ⊢ ES_prime[1 mod 840]? T ⊢ (MS)?
* **Q2 (brief).** Does IΔ₀ + exp prove every true Π₁ sentence "with polynomially bounded witnesses"?
* **Attack A (model side, "global landing").** Which models of which theories admit a *single* ring homomorphism
  e: M → ℤ together with a path to the order at infinity (Shepherdson's model; U64's M_{q*=1}, where NOI ⊬ (MS) is
  "4 > 3" transported along an arc)? Target theorems: (G) no nonstandard model of IE₁ has a ring homomorphism to ℤ;
  (E) a Bezout model with global landing in which (MS) fails.
* **Attack B (arc side).** Replace U64's analytic arcs by a real-spectrum / semialgebraic-component criterion (local:
  one landing point per finitely generated subring).
* **Attack C (killer side).** Which T prove a *robust* certificate that has no integer point at odd squares (NR,
  negative Pell, ...)? Such a T has no arc counter-models at all (L65 Prop 5.1).

**Why not closed.** U64/L65 settled NOI + GCD + PD + Th_∀(ℤ) + T1 + TS and showed that *polynomial-type* models cannot
satisfy Bez / PB / QR_std / Lag. IE₁, IΔ₀, IΔ₀ + exp and OI + Bez were OPEN (L65 §6, §9 O1′). Nothing below repeats
the U64/L65 constructions; the new ingredients are (i) the D + M / global-landing structure theory, (ii) Wilmers' and

## 2. First results (checkpoint 1; proofs to be written out in §§3–5 of the final memo)

* **Q2 answer (PROVED from literature, VERIFIED).** No. Every Π₁ sentence is ∀Δ₀, and Con(Q) is a true ∀Δ₀ sentence
  that IΔ₀ + exp does not prove (Hájek–Pudlák, *Metamathematics*, Cor. V.5.29). The exact description of the Π₁
  theorems of IΔ₀ + exp is Wilkie's theorem (HP Thm V.5.26): for bounded φ, IΔ₀ + exp ⊢ ∀x φ(x) iff Q ⊢ ∀x (I(x) → φ(x))
  for some cut I definable in Q, iff Q interprets Q + ∀x φ(x).
* **Lemma G1 (PROVED, elementary).** If M is a discretely ordered ring with division with remainder by numerals (e.g.
  M ⊨ IOpen) and e: M → ℤ is a ring homomorphism, then x ≡ e(x) (mod k) for all x ∈ M, k ≥ 1; D := ker e = ⋂_k kM is
  a ℚ-vector space and M = ℤ ⊕ D. If moreover M ⊨ Bez, no two nonzero elements of D are coprime.
* **Theorem G (PROVED relative to Smith JPAA 1992 (IE₁ ⊢ Bez; abstract VERIFIED) and Wilmers 1985 / McAloon as quoted
  verbatim by D'Aquino, NDJFL 38 (1997) (VERIFIED quote)).** No nonstandard model of IE₁ (hence of IΔ₀, PA) admits a ring
  homomorphism to ℤ. Proof idea: pass to a nonstandard initial segment I ⊨ PA (Wilmers); for a ∈ ker e ∩ I nonstandard,
  its 2-power part and 3-power part both lie in ker e and are coprime, contradicting Lemma G1.
  *Reading:* the "4 > 3" mechanism (one global landing point) is unavailable for IE₁; any IE₁ counter-model must land
  at points that vary with the finitely generated subring.
* **Theorem E (PROVED, elementary; first model).** M_E := ℤ + xℚ[x] (x positive infinite) is a discretely ordered
  Bezout domain which is an integer part of its fraction field (so M_E ⊨ IOpenLin by Glivická–Glivický Thm 3), every
  prime of M_E generates a maximal ideal (PB), n := x + 1 is prime with n ≡ 1 (mod k) for all k, and
  M_E ⊨ ¬ES(n) ∧ ¬ES★(n) (path s ∈ [0, ∞), landing at x = 0, R(1) = 0). Hence **IOpenLin + Bez + PB ⊬ (MS)**.
  Together with U64 (NOI ⊬ (MS); NOI ⊇ IOpen = IOpenLin + eIOpen, Glivická–Glivický Cor 6) this isolates
  **IOpen + Bez** as the first open combination, and Theorem G shows its counter-models, if any, cannot extend to IE₁
  with a global landing.

## 3. Pre-registered kill tests

* **K1 (Theorem E, computational falsifier).** Exhaustive search, in M_E, for (★) solutions 4uBC − u − B = n and ES
  solutions with u, B, C (resp. x, y, z) of degree ≤ 2 in x and rational coefficients of height ≤ H, for n = x + 1 and
  n = x² + 1 (expected: 0). Positive control: n = 8x + 5 (landing value 5, ES(5) solvable; expected: solutions found).
  KILL if any solution is found for n(0) = 1, or none for the control.
* **K2 (Theorem G).** Proof-level: the argument must not use any property of e beyond being a ring homomorphism; the
  reviewer checks that the initial segment I is a subring-generating cut closed under ·, and that the 2/3-power
  splitting is a theorem of PA (it is of IΔ₀). KILL if the cited Wilmers/McAloon statement is misquoted.
* **K3 (Attack C).** If an arc-killing certificate is claimed provable in a theory T, it must have no integer point at
  every odd square *and* be positively closed (L65 Lemma 2.1); the claim is killed by exhibiting an arc model of T.
