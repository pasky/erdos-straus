## §1 Three faces of R (PROVED; CERTIFIED for n ≡ 1 (4), n < 400, `z62_inversef_basic.py`)

**Theorem 1.1.** For every n ≥ 1,
 R(n) = #{(u,B) ∈ ℕ² : 4uB | n+u+B}                                  (face Y)
   = #{(C,d) : C ≥ 1, d | 4Cn+1, d ≡ −1 (mod 4C)}                       (face C)
   = #{(d,r) : d ≡ 3 (mod 4), 4r | d+1, d | n+r}.                        (face d)

*Proof.* (Y): C = (n+u+B)/(4uB) is determined. (C): given (u,B,C) put d = 4uC−1; then d(4BC−1) = 16uBC² − 4C(u+B) + 1 = 4C(4uBC−u−B) + 1 = 4Cn+1, so d | 4Cn+1 and d ≡ −1 (4C). Conversely, if d | 4Cn+1 with d ≡ −1 (4C), put d' = (4Cn+1)/d; from dd' ≡ 1 and d ≡ −1 (mod 4C) we get d' ≡ −1 (4C); u = (d+1)/4C, B = (d'+1)/4C are integers and 4uBC − u − B = ((d+1)(d'+1) − (d+1) − (d'+1))/4C = (dd'−1)/4C = n. The maps are mutually inverse. (d): r := u, d := 4uC−1; from B(4uC−1) = n+u we get d | n+r and 4r | d+1; conversely C = (d+1)/4r, B = (n+r)/d, u = r. ∎

Consequences: R(n) = 0 ⟺ ∀r ≥ 1: n+r has no divisor ≡ −1 (mod 4r) ⟺ ∀C ≥ 1: 4Cn+1 has no divisor ≡ −1 (mod 4C) ⟺ ∀d ≡ 3 (4): (−n mod d) ∤ (d+1)/4. Only C ≤ (n+2)/4 can contribute (both cofactors are ≥ 4C−1, so (4C−1)² ≤ 4Cn+1).

## §2 Quadratic-residue structure (PROVED), and what R(p)=0 really forces

**Lemma 2.1 (odd squares; the model case).** If d ≡ 3 (4) and d ≡ −1 (mod 4r) then the Jacobi symbol (−r/d) = −1. Hence R(m²) = 0 for every odd m.
*Proof.* r odd: (r/d)(d/r) = (−1)^{(r−1)/2·(d−1)/2} = (−1)^{(r−1)/2} since (d−1)/2 is odd; and (d/r) = (−1/r) = (−1)^{(r−1)/2}; so (r/d) = 1 and (−r/d) = (−1/d) = −1. r = 2^a r', a ≥ 1: d ≡ −1 (mod 8) so (2/d) = 1, and (r'/d) = 1 as before (d ≡ −1 mod 4r'); again (−r/d) = −1. If d | m²+r with 4r | d+1 then gcd(d,m) = 1 (a common prime would divide r and d+1), so −r ≡ m² (mod d) gives (−r/d) = +1, contradiction. ∎

**Lemma 2.2 (character identity).** Let C ≥ 1 and q an odd prime with q | 4Cp+1. Then
 (q/p) = (p/q) = (−C/q) =: χ_C(q),
and q ↦ (−C/q) depends only on q mod 4C; it defines a character χ_C of (ℤ/4C)^× with χ_C(−1) = −1.
*Proof.* 4Cp ≡ −1 (q) gives −Cp ≡ (2^{-1})² so (−C/q)(p/q) = 1; (p/q) = (q/p) by reciprocity (p ≡ 1 mod 4). Writing C = 2^a C', (−C/q) = (−1/q)(2/q)^a(C'/q) and (C'/q) = (q/C')(−1)^{(C'−1)(q−1)/4}: each factor depends on q mod 8 (if a ≥ 1, 8 | 4C) or mod 4C'. Value at q ≡ −1 (mod 4C): (−1/q) = −1, (2/q) = 1 if a ≥ 1, (C'/q) = 1 by the computation in Lemma 2.1. ∎

**Theorem 2.3 (arrangement characterization).** Let C ≥ 1, 4Cp+1 = ∏ q_i^{e_i}, H := ker χ_C (index 2 in (ℤ/4C)^×, −1 ∉ H). Then q_i mod 4C ∈ H ⟺ (q_i/p) = +1, and
 R has a hit at C (some (u,B) with this C) ⟺ some sub-multiset of the prime factors (with multiplicity) has product ≡ −1 (mod 4C).
Write each prime factor as q ≡ χ_C(q)·h(q) (mod 4C) with H-component h(q) := χ_C(q)·q mod 4C ∈ H (so (ℤ/4C)^× = H × {±1}). In particular: (a) if every prime factor of 4Cp+1 is a QR mod p, there is no hit at C; (b) the number of QNR-mod-p prime factors (with multiplicity) is even; (c) a hit needs a sub-multiset with an ODD number of QNR factors whose H-components h(q) multiply to 1; e.g. if 4Cp+1 = q₁q₂ with q₁ QNR mod p, a hit occurs iff q₁ ≡ −1 (mod 4C).
*Proof.* Face C of Thm 1.1 plus Lemma 2.2; (b): ∏χ_C(q_i)^{e_i} = χ_C(4Cp+1) = χ_C(1) = 1. ∎

So **R(p) = 0 ⟺ for every C ≤ (p+2)/4, the QNR-mod-p prime factors of 4Cp+1 are "arranged" so that no sub-product (together with QR factors) is ≡ −1 (mod 4C)**. For n = m² (any odd m) the analogue holds vacuously: every prime q | 4Cm²+1 has Legendre symbol (m²/q) = +1, so all residues lie in H (Lemma 2.2's proof only uses 4Cn ≡ −1 mod q). This is the exact inverse statement; everything "square-like" about R-zeros is a shadow of it.

**Corollary 2.4 (rigid consequences of R(n) = 0, n ≡ 1 (4); PROVED).** (i) n ≡ 1 (mod 8) [face Y with (u,B) = (1,2): 8 | n+3 ⟺ n ≡ 5 (8)]. (ii) every prime factor of 4n+1 is ≡ 1 (mod 4) [face C, C = 1]. (iii) for every prime ℓ ≡ 3 (4): n mod ℓ ∉ {−r : r | (ℓ+1)/4} [face d, d = ℓ]; e.g. n ≢ 2 (3); n ≢ 5,6 (7); n ≢ 8,10 (11); n ≢ 14,18 (19); n ≢ 17,20,21,22 (23). (iv) n ≢ 3 (mod 5) if 3 ∤ n [d = 3 handles n ≡ 2 (3), d = 15 with r = 2 handles n ≡ 13 (15)]. (v) [face d, r = 2] n+2 has no divisor ≡ 7 (mod 8); since n+2 ≡ 3 (4) has an odd number of prime factors ≡ 3 (4), hence (7 (8) being excluded) some factor ≡ 3 (8), no prime factor ≡ 5 (8) can occur: all prime factors of n+2 are ≡ 1 or 3 (mod 8).

**What is NOT forced (PROVED by example, from the 14 zeros).** "p is a square mod ℓ" is not forced at ℓ = 5, 7, 11, 23: 577 ≡ 2 (5), 409 ≡ 3 (7), 5212561 ≡ 2 (11), 9601 ≡ 10 (23). (For primes ℓ ≡ 1 (4) no single class mod ℓ is excluded by any one (d,r): face d needs ℓ | d ≡ 3 (4), so the excluded class lives mod ℓd'', not mod ℓ; unions can exclude more, cf. (iv).) "p+k has no odd prime factor q ∤ k with (−k/q) = −1" (no *inert* odd prime of Q(√−k); ramified primes and 2 are not counted) is not forced: `z62_inversef_struct.py` — over k ≤ 24 it fails at 9.1 values of k on average for the 14 zero primes, vs ≈ 17.5 for random primes ≡ 1 (4) of the same size. [Parity remark, PROVED: for even k < p let ν_k be the number, with multiplicity, of prime factors q of p+k with (−k/q) = −1 (all such q are odd and coprime to k since p+k is odd and ≡ p mod k). Then (−1)^{ν_k} = (−4k/(p+k)) (Jacobi, multiplicative in the lower argument), and (−4k/·) is a character mod 4k, so the parity of ν_k is a function of p mod 4k alone; it can be identically +1 on p ≡ 1 (4) (k = 4: (−16/(p+4)) = (−1/(p+4)) = 1) or take both signs.]

**§2.5 Statistical square-likeness (EVIDENCE, `z62_inversef_qnr.py`, `data/z62/inversef/qnr_stats.txt`).** Over C ≤ 40, the number of QNR-mod-p prime factors of 4Cp+1 (with multiplicity) is 20–46 for the 14 zero primes vs 32–90 for random primes ≡ 1 (8) of the same size; the number of C ≤ 40 with "all-QR" is 18–31 vs 4–24. Zero primes are clearly biased toward Theorem 2.3(a) but are far from satisfying it for all C — the arrangement condition (c) does the rest.

## §3 All ES solutions of a prime p ≡ 1 (4) (PROVED; CERTIFIED exhaustive for p < 80, `z62_inversef_identities.py`)

Let 4/p = 1/x+1/y+1/z. Then p divides exactly one or exactly two of x,y,z (all three is impossible: 4 = 1/x'+1/y'+1/z' has no solution).

**Theorem 3.1 (case (ii): p | y, p | z, p ∤ x).** The solutions are exactly
 x = g'YZ, y = p·m·g'·Y, z = p·m·g'·Z   where g',Y,Z,s ≥ 1, gcd(Y,Z) = 1, s | Y+Z, m := (Y+Z)/s, and **p + s = 4g'YZ**;
and conversely every (g',Y,Z,s) with s | Y+Z and p + s = 4g'YZ (no coprimality needed) gives a solution by the same formulas. R(p) is the sub-family s = Y+Z (m = 1). Class form: p ≡ −4g'Y² (mod 4g'Ym − 1).
*Proof.* Write y = py', z = pz'. Clearing denominators: x(4y'z' − y' − z') = p·y'z'. Let g = gcd(y',z'), y' = gY, z' = gZ, gcd(Y,Z) = 1, κ' := 4gYZ − Y − Z, so xκ' = pgYZ. Since gcd(κ', YZ) = gcd(Y+Z, YZ) = 1, κ' | pg. If p ∤ κ' then κ' | g and x = p(g/κ')YZ, contradicting p ∤ x. So κ' = pκ'' with κ'' | g; put g = κ''g'; then x = g'YZ, and Y+Z = 4gYZ − pκ'' = κ''(4g'YZ − p), so s := (Y+Z)/κ'' is a positive integer with p + s = 4g'YZ and m = κ''. Conversely 1/(g'YZ) + 1/(pmg'Y) + 1/(pmg'Z) = (pm + Y + Z)/(pmg'YZ) = m(p+s)/(pmg'YZ) = 4/p. ∎

**Theorem 3.2 (case (i): p | z only).** The solutions are exactly
 x = bh(a+b)/t, y = ah(a+b)/t, z = p·a·b·h   where t ≡ 3 (4), gcd(a,b) = 1, t | a+b, and **pt + 1 = 4abh**;
and conversely every (a,b,h,t) with t ≡ 3 (4), t | a+b, pt+1 = 4abh (no coprimality needed) gives a solution by the same formulas.
*Proof.* z = pw; 4/p − 1/(pw) = (4w−1)/(pw) = 1/x + 1/y, so pw(x+y) = (4w−1)xy; p ∤ xy forces 4w − 1 = pt, and t ≡ 3 (4) as p ≡ 1 (4). Then 1/x+1/y = t/w ⟺ (tx−w)(ty−w) = w²; the divisor δ = tx − w of w² satisfies δ ≡ −w (mod t), and conversely any such δ gives integer x = (w+δ)/t, y = (w+w²/δ)/t (δ is coprime to t because gcd(w,t) = 1; w²/δ ≡ δ ≡ −w mod t). Writing δ = wb/a with a = w/gcd(w,δ), b = δ/gcd(w,δ) (both divide w since δ | w², and gcd(a,b) = 1), the condition is b ≡ −a (mod t). Put h := w/(ab) (an integer since a, b are coprime divisors of w); then pt+1 = 4w = 4abh. (If one starts from an arbitrary pair a | w, b | w with t | a+b, writing a = ga₁, b = gb₁ gives t | g(a₁+b₁) and gcd(t,g) = 1 (g | w, 4w ≡ 1 mod t), so t | a₁+b₁ and (a₁,b₁,w/(a₁b₁)) is a normalized triple.) The displayed x,y,z are integers (t | a+b) and 1/x+1/y+1/z = t/(abh) + 1/(pabh) = (pt+1)/(pabh) = 4/p. ∎

`z62_inversef_identities.py` enumerates both families (converse direction, all (Y,Z,s) and all divisor pairs (a,b) of w for t < 2p²) and compares with a brute-force list of ALL solutions for every prime p ≡ 1 (4), p < 80: no solution is missed and none is spurious (CERTIFIED).

**Lemma 3.3 (Schinzel's obstruction in normal form; PROVED).** Let n = m² with m odd. (a) There are no (g',Y,Z,s) with s | Y+Z and n + s = 4g'YZ. (b) There are no (a,b,h,t) with t ≡ 3 (4), t | a+b and nt + 1 = 4abh.
*Proof.* (a) Put μ := (Y+Z)/s (the ratio; m is the square root) and d := 4g'Yμ − 1 ≡ 3 (4). From n + s = 4g'YZ and μs = Y+Z: (4g'Yμ−1)(4g'Zμ−1) = 16g'²YZμ² − 4g'μ(Y+Z) + 1 = 4g'μ²(n+s) − 4g'μ²s + 1 = 4g'μ²n + 1. So 4g'μ²n ≡ −1 (mod d), i.e. −g'·n ≡ (2μ)^{−2} (mod d) (gcd(2μ,d) = 1 as d ≡ −1 mod 4μ), whence (−g'/d)(n/d) = 1. Now gcd(d, m) = 1 for n = m² (a common prime would divide 4g'μ²n+1), so (n/d) = 1 and (−g'/d) = 1. But d ≡ −1 (mod 4g') and Lemma 2.1 gives (−g'/d) = −1. Contradiction. (b) w := (nt+1)/4 = abh. For an odd prime q | w: nt ≡ −1 (mod q), q ∤ m, so (−t/q) = 1; by reciprocity ((t/q)(q/t) = (−1)^{(q−1)/2} as (t−1)/2 is odd) (−t/q) = (−1/q)(t/q) = (q/t), so (q/t) = 1. If 2 | w then m²t ≡ −1 (mod 8), so t ≡ 7 (8) and (2/t) = 1. Hence every divisor a of w has Jacobi symbol (a/t) = 1 (gcd(a,t) = 1 as 4w ≡ 1 mod t). If a + b ≡ 0 (mod t) with a, b | w then (a/t) = (−1/t)(b/t) = −1, contradiction. ∎
(These are statements about the two parametric forms with n in place of p; for composite n the equation 4/n = 1/x+1/y+1/z has other solutions, e.g. 4/9 = 1/3+1/18+1/18, which is not of either form.)

## §4 Polynomial identities for prime p: complete list (PROVED)

**Definition.** An *identity family* is a residue class 𝒦 = {p ≡ c (mod D)} together with parameters (g',Y,Z,s) resp. (a,b,h,t) that are integer-valued polynomials in p (rational coefficients) on 𝒦 and satisfy the *converse* conditions of Thm 3.1 resp. 3.2 (s | Y+Z, p+s = 4g'YZ; resp. t ≡ 3 (4), t | a+b, pt+1 = 4abh — no coprimality imposed) for all sufficiently large p ∈ 𝒦. Each identity family gives an explicit ES solution for every large prime in 𝒦 (Thms 3.1/3.2, converse parts). Mordell's identities are of this kind.

**Lemma 4.0.** If P, Q ∈ ℚ[p], Q ≠ 0, and P(p)/Q(p) ∈ ℤ for infinitely many integers p, then Q | P in ℚ[p]. *Proof.* P = QS + T with deg T < deg Q; T(p)/Q(p) = P/Q − S(p) lies in (1/N)ℤ for a fixed N (denominators of S) and tends to 0, so it vanishes for all large such p; T has infinitely many roots, T = 0. ∎ Hence m = (Y+Z)/s and e = (a+b)/t are polynomials, and degrees add.

**Proposition 4.1 (= Elsholtz–Tao Prop 1.9; rediscovered here, not new).** Every identity family (in the sense of the Definition above — parameters polynomial in p) is *contained in* an admissibility class of one of the following seven normal forms (with positive integer constants; sub-progressions of the listed class and the symmetric swaps are allowed — e.g. fixing (Y,Z,s) = (1,2,3) on p ≡ 5 (16) is an identity family whose maximal (A)-class is p ≡ 5 (8)):
 case (ii): (A) (Y,Z,s) constant, g' linear: class p ≡ −s (mod 4YZ), s | Y+Z.
     (B) (g',Z,m) constant, s linear, Y = ms − Z: class p ≡ −4g'Z² ≡ −Z·m⁻¹ (mod 4g'Zm − 1).
     (C) (g',Z,s) constant, m linear, Y = ms − Z: class p ≡ −(s+4g'Z²) (mod 4g'Zs).
 case (i): (A') (a,b,t) constant, h linear: class p ≡ −t⁻¹ (mod 4ab), t | a+b, gcd(t,2ab) = 1.
     (B') (a,h,t) constant, b = te − a with e linear: class p ≡ −(4a²h+1)/t (mod 4ah), t | 4a²h+1.
     (F1) (b,e,λ) constant: h = (p+λ)/4be, a = (pb+e)/λ, t = (a+b)/e (t linear in p): class {p ≡ −λ (4be), λe | pb+e+λb}.
     (F3) (e,h,λ) constant: a = (p+λ)/4eh, t = (4a²h+1)/λ, b = te − a (t quadratic): class {p ≡ −λ (4eh), λ | 4a²h+1}.
(In (B),(C),(F3) the roles of the two symmetric parameters may be swapped.) The classification is of the already-polynomial master parameters; classifying polynomial *denominators* (x,y,z) additionally needs Elsholtz–Tao's finite residue-subdivision/gcd argument and is not redone here.
*Proof.* Case (ii). Since s > 0 for large p, deg(p+s) = max(1, deg s), and deg g' + deg Y + deg Z = deg(p+s); also deg m + deg s = deg(Y+Z) ≤ max(deg Y, deg Z). If deg s ≥ 2 then deg g' + deg Y + deg Z = deg s ≤ max(deg Y, deg Z), so g' is constant and one of Y, Z, say Z, is constant; then deg s = deg Y so m is constant, and from p + (Y+Z)/m = 4g'YZ we get Y = (mp+Z)/(4g'Zm−1), linear — contradicting deg Y = deg s ≥ 2. So deg s ≤ 1 and exactly one of g',Y,Z is linear. If g': Y,Z constant, s | Y+Z constant: (A). If Y (Z,g' constant): ms = Y+Z is linear, so either m constant and s linear — then Y = ms − Z and p = 4g'Z(ms−Z) − s = s(4g'Zm−1) − 4g'Z²: (B); or s constant and m linear — p = 4g'Zs·m − 4g'Z² − s: (C). Case (i). Put e := (a+b)/t (polynomial by Lemma 4.0). Then 1 + deg t = deg a + deg b + deg h and deg t + deg e = deg(a+b) ≤ max(deg a, deg b) (a, b > 0). WLOG deg a ≥ deg b. If deg t = 0: one of a, b, h is linear; h linear gives (A'); a linear (b, h constant) gives e = (a+b)/t linear, a = te − b: (B') with a,b renamed; b linear is excluded by deg a ≥ deg b unless a is linear too, which contradicts the degree sum. If deg t ≥ 1: deg b + deg h = 1 + deg t − deg a ≤ 1 + deg t − (deg t + deg e) ≤ 1.
 – (deg b, deg h) = (0,0): t | a + b and from pt+1 = 4abh, t | 4b²h·… more simply a ≡ −b (mod t) gives 4abh ≡ −4b²h, so pt + 1 ≡ −4b²h, i.e. t | 1 + 4b²h, a constant: t bounded, contradiction.
 – (0,1): deg a = deg t and deg e ≤ deg a − deg t = 0, e constant. From pt + 1 = 4abh with t = (a+b)/e: a(4bhe − p) = pb + e. Put λ := 4bhe − p ∈ ℚ[p], deg λ ≤ 1, λ | pb + e in ℚ[p] (Lemma 4.0). If deg λ = 1 then a is constant, contradicting deg a = deg t ≥ 1. So λ is a constant, and an integer (= 4beh − p at any p ∈ 𝒦); h = (p+λ)/4be, a = (pb+e)/λ, t = (a+b)/e: (F1).
 – (1,0): deg a = deg t ≥ 1, e constant, b = te − a. From pt + 1 = 4ah(te − a): t·u = 4a²h + 1 with u := 4aeh − p. If u is constant then a = (p+u)/(4eh) is linear and t = (4a²h+1)/u quadratic, contradicting deg a = deg t. So deg u ≥ 1 and u | 4a²h+1 in ℚ[p]. Modulo u, 4aeh ≡ p, so 4e²h(4a²h+1) = (4aeh)² + 4e²h ≡ p² + 4e²h; thus u | p² + 4e²h, which is irreducible over ℚ (no rational root), so u = c(p² + 4e²h) with c ∈ ℚ^×. Then a = (u+p)/4eh, and with q := p²+4e²h one computes (cq+p)² + 4e²h = q(c²q + 2cp + 1), so t = (c²q+2cp+1)/(4ce²h) and b = te − a = (cp+1)/(4ceh). Put λ := 1/c; b = (p+λ)/4eh is integer-valued so λ ∈ ℤ, and then t = (4b²h+1)/λ, a = te − b: this is (F3) with a, b swapped. ∎

**Lemma 4.2 (Schinzel).** No identity family's class 𝒦 = {p ≡ c (mod D)} has c a square modulo D (c coprime to D). Hence a class a (mod M) with a a square mod M is never a finite union of identity-family classes.
*Proof.* If c ≡ m₀² (mod D), the class contains odd squares n = m² with m arbitrarily large: take m = m₀ + kD; if D is even then m₀ is odd (c is odd) and so is every m; if D is odd choose k of the right parity. At such n the family's parameters are integers satisfying the converse conditions of Thm 3.1/3.2 with n in place of p, contradicting Lemma 3.3. The second statement: a finite union of classes covering a (mod M) would cover the odd squares in it. ∎

## §6 Why the "structure ⟹ other solution" half did not close (EVIDENCE + heuristic)

1. **The complete inverse statement is the sieve.** R(p) = 0 ⟺ p avoids every R-class ((A) with s = Y+Z: −(Y+Z) mod 4YZ; (B) with m = 1: −Y mod 4g'Y−1). Any "square-like" statement forced by R = 0 is a reformulation of avoiding these classes (Cor 2.4 lists the rigid ones). The R-classes are a sub-family of the identity classes, so "R(p) = 0 ⟹ p lies in an identity class with bounded parameters" is a statement about finite covers of residue classes by identity classes.
2. **The identity-cover program and how it would close.** If for each prime ℓ all classes a (mod M_ℓ) with (a/ℓ) = −1 were finite unions of identity classes (with M_ℓ and the parameter bounds polynomial in ℓ), then every prime p ≡ 1 (4) would have an ES solution: if p ≡ 5 (8) then R(p) ≥ 1 (Cor 2.4(i)), so assume p ≡ 1 (8), whence 2 is a QR and the least QNR ℓ of p is an odd prime with (p/ℓ) = (ℓ/p) = −1. Since all seven forms yield positive parameters at every admissible n (e.g. (B): Y = (μn+Z)/D > 0; (B'): b = (nt+1)/(4ah) > 0; (F3): b = (an+e)/λ > 0), no size threshold and hence no Burgess bound (ℓ ≤ p^{1/(4√e)+ε}) is needed for the qualitative implication; the existence of a QNR suffices **if** the finite covers exist. Lemma 4.2 is no obstruction (such a is not a square mod M_ℓ). This is a PROGRAM; no such cover is established. This is exactly the "structure (p is not a square mod ℓ) ⟹ explicit solution" shape the brief asks for; it uses primality only through "p is not a QR modulo everything".
3. **It does not close at the moduli tested, already for ℓ = 11** (§5): four non-square classes mod 9240 stay uncovered, and refining by 2,3,5,7,13,17,19 leaves a growing number of uncovered sub-classes. Heuristic reason (not a proof): for family (B) the class c (mod D) has Jacobi symbol (c/D) = (−Z m⁻¹/D) = −1 (Lemma 2.1 with r = Z, r = m), so a class that is QNR only at ℓ and QR at every other prime ≤ X can be hit by a (B)-class only if ℓ occurs to an odd power in D; assuming the other families behave alike, the sieve weight of those D up to X is of order (log X)²·(log log X)/ℓ, so the uncovered density inside such classes at level X is roughly exp(−c(log X)²/ℓ) > 0 for every finite X. An exact finite cover would be a coincidence of the Mordell-840 type; the computations say it does not recur at 11, 13, 17 up to the sizes tried. Whether such covers exist for larger moduli is OPEN; nothing here proves they do not.
4. **The 14 zeros do not point to a hidden second family.** `z62_inversef_other.py` (`data/z62/inversef/other_families.txt`): counts R^{(m)}(p) of case-(ii) solutions with (Y+Z)/s = m, m ≤ 6, and of normalized (coprime (a,b)) case-(i) solutions per t ≤ 63. At the zero primes R^{(2)} ranges 0–16 (102001 and 8813281 have R^{(2)} = 0) vs 4–34 for random primes ≡ 1 (8) of the same size; normalized case-(i) totals over t ≤ 63 are 4–29 at the zeros (mean 11.6; for the eight zeros above 10⁵: 4, 4, 11, 15, 16, 17, 17, 20) vs 6–39 at random primes (mean 19.5; the eight random primes above 10⁵: 16, 18, 21, 23, 24, 30, 36, 39). Assessment (EVIDENCE; controls are size-matched but not class- or failure-matched): the other families are mildly *suppressed* at R-zeros (consistent with §2.5 square-likeness); no forcing theorem "R = 0 ⟹ R^{(m)} ≥ 1" was obtained, and low counts do not refute a conditional positivity statement — they only show none is suggested by the data.
5. Consequently "R(p) = 0 ⟹ [square-like] ⟹ [other solution]" has the wrong sign: square-likeness pushes every family toward zero simultaneously; what distinguishes a prime from a square is that it is not a square mod everything (least-QNR), and one sufficient way to convert that into an explicit solution would be the finite covers of §6.2 — none were found.

## §8 Residual questions worth a lane
* Is there a provable obstruction (à la Schinzel) showing that the class 2041 (mod 9240) is not a finite union of identity classes? To refute a specific finite cover one needs one integer of the class outside all its classes; to refute all finite covers one needs, for every finite set of identity classes, such an integer. The heuristic count of non-square n ≤ X outside *all* identity classes is X·exp(−c log²X) → 0, so the uncovered set probably has density 0 inside the class and the non-coverability (if true) is "soft": a proof would need a new invariant.
* The arrangement condition of Thm 2.3 is a clean target for a bilinear count: R(p) ≥ #{C : 4Cp+1 = q₁q₂, q₁ ≡ −1 (4C)}, i.e. primes q₁ ≡ −1 (mod 4C) with (4Cp+1)/q₁ prime. That is the standard analytic route, not an inverse one.
