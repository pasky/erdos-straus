# z15_density_thin — why richer menus cannot reach the (J)54 sterile Mordell points (O240)

## Idea
The escape mechanism of Theorems B/C needs the parameter to live on a thin set (curve n = φ(X), exponential family) where
the descent class of the parameter differs from the square class of n. A finite set of thin items covers a density-0 set of
primes (Prop 5.1), so near the (J)54 points (all primes in an r-generic cylinder) the ET-uncoverable neighbourhood still
contains a positive density of uncovered primes. Positive-density parametrisations (norm forms) have element squares
y² ↦ N(y)², so actual squares are Zariski-dense in every class and sector and T1 survives ((J)3).
