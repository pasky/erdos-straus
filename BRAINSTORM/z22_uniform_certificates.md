# z22_uniform_certificates — self-generated certificates classified; odd-order witness (O250; CAP_BOUNDED §2)

**Idea.** Use only K, 2^{v₂K}, p (exponent δ_s = j·b_s on every odd s | K). Every forced argument is of this kind.
**Result (PROVED).** Prop 2.1: a uniform certificate exists iff m | N for an explicit N = num(2^w p^J + 1): cap 0 gives
the classical p + 4, p + 1, 2^c p + 1, p + 2^c, p² + 2^c; cap ≥ 1 gives only p^j + 4^j (K odd, j odd) or p^J + 2^c.
Cor 2.2: for p ≡ 1 (8) every p-dependent N is ≡ 1 (4) or has the wrong class mod 8, so p mod 8 alone forces nothing;
congruence forcing only through fixed small primes of N (classical classes, e.g. 3 | p + 4 for p ≡ 17 (24)) —
R-O250 review fix (the first version wrongly said "never congruence-forced").
Prop 2.3 (odd-order witness): at a forced window q with K odd, e*(p) ≤ (o − 1)/2·max b_s, o = odd part of
ord_q(p/4); the cap is independent of the size of q (q | p^o + 4^o can be ≈ p^o).
**Barrier screen.** (U) "some p^o + 4^o, o ≤ O₀, has a prime factor ≡ 3 (8)" is a simultaneous Landau event about
correlated values; a naive heuristic (speculative) suggests failure i.o. for every fixed O₀. T1: p^o + 4^o at p = a² is a sum of two coprime squares.
**Label.** PROVED (classification, witness); Assessment (no route to bounded cap).
