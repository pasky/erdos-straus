# bsD_frobenius_closure — every reciprocity obstruction to an ES slice is quadratic, because the divisor conditions split in a quadratic field (O177)

**ES is not solved here.** Labels as in DISCOVERIES.md. Script `scripts/bsD_cubic_test.py`.

## Idea
Direction (a) asks for a "degree-k Diff-parity" forcing an order-k ray condition. Abstract what T1 actually uses:
(i) every prime factor ℓ of the certificate integer N lies in a Chebotarev set S (a splitting condition), (ii)
multiplicativity of Dirichlet characters, (iii) the target class (−1 or −p mod M). The order of the characters that can
appear is then dictated by the Galois group of the splitting field in (i) intersected with ℚ(ζ_M). Compute it.

## Statement
Type II slice (c, d) at odd n: M = 4cd, N = 1 + 4c²dn; event E_II: ∃ f | N, f ≡ −1 (M). Type I: N = n² + 4c²d,
target −n. Every prime ℓ | N (Type II) satisfies ℓ ∤ Mn and (−dn/ℓ) = 1 (since −dn ≡ (2c)^{−2} mod ℓ); Type I: ℓ ∤ M,
(−d/ℓ) = 1 for ℓ ∤ n. Let K = ℚ(√−dn) (II), K = ℚ(√−d) (I), S_K = primes split in K, and the **Frobenius closure**
Φ := subgroup of (ℤ/M)^× generated by the classes of ℓ ∈ S_K, ℓ ∤ M (a semigroup in a finite group is a group).

**Theorem 2 (PROVED, Chebotarev).** Φ = Gal(ℚ(ζ_M)/K ∩ ℚ(ζ_M)), i.e. Φ = (ℤ/M)^× if K ⊄ ℚ(ζ_M) and Φ = ker ψ_K
(index 2) if K ⊂ ℚ(ζ_M). Consequently:
(a) the only obstruction to E_II / E_I visible from "prime factors split in K + multiplicativity" is the quadratic
character ψ_K, and it is effective iff K ⊂ ℚ(ζ_M) and ψ_K(target) = −1. Type II: target −1, ψ_K(−1) = −1 (K
imaginary), so a slice is obstructed iff ℚ(√−dn) ⊂ ℚ(ζ_{4cd}) — at n = p ∤ 4cd never; at n = m² always (T1);
Type I: obstructed iff (−d/n) = +1 (the BL level condition).
(b) characters of odd order never separate −1 from 1 (χ(−1)² = 1 = χ(−1)^k ⇒ χ(−1) = 1), so a T1-type
contradiction "χ(f) forced ≠ χ(target)" for Type II needs χ odd, and by (a) χ = ψ_K.
*Proof.* ℚ(ζ_M) and K are abelian; by Chebotarev in Kℚ(ζ_M), the Frobenii of ℓ ∈ S_K restricted to ℚ(ζ_M) are
exactly the elements trivial on K ∩ ℚ(ζ_M), each hit by infinitely many ℓ; K ∩ ℚ(ζ_M) is ℚ or K. ∎
**Cubic dictionary (PROVED via cubic reciprocity, for orientation).** For a prime q ≡ 1 (3), q = ππ̄ in ℤ[ζ₃], and
rational f ≡ ±1 (3) prime to q: (f/π)₃ = ∏_{ℓ | f} (π/ℓ)₃^{v_ℓ(f)} (cubic reciprocity, f primary up to sign; −1 is a
cube). So the cubic part of "f ≡ −1 (mod q)" is "∏_{ℓ|f}(π/ℓ)₃^{v_ℓ(f)} = 1" (R177 repair: a product condition, not each factor) — a **Kummer splitting**
condition in ℚ(ζ₃, π^{1/3}), non-abelian over ℚ. ES's N are values of *quadratic* norm forms, whose prime factors
carry no Kummer-cubic constraint; so cubic reciprocity can enter ES only through auxiliary data, never forced.

## Barrier screen
* **Hypotheses → escapes.** Theorem 2 assumes the information about ℓ | N is "ℓ ∈ S_K". To force order-k data one
  needs certificate integers N that are **norms from a field containing a degree-k Kummer or cyclic extension
  inside ℚ(ζ_M)·K'** — e.g. N = N_{L/ℚ}(linear form) for L ⊇ ℚ(ζ₃, ∛q). ES certificates are not of this shape
  (N_θ(p) = p² + 4c²d, 1 + 4c²dp, (p+e)/4, (pe+1)/4: binary quadratic). A family where they are would be a *subfamily
  of slices* with extra structure — it can only *reduce* coverage (Theorem 2 is about obstructions), so the escape
  produces obstructions, not existence. Recorded as a negative.
* **T1** passes (Theorem 2(a) recovers it). **B2**: Theorem 2 is the Chebotarev (density) shadow; existence inside a
  slice is a single-N divisor event (B2). **B1**: the "cubic effects" seen numerically are congruences of p (below).
