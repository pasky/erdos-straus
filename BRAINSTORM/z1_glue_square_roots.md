# z1_glue_square_roots — Siegel–Weil sees the square-root class, the path needs the residue ±1 (brief angle 1, mass side) (O224)

## Idea
Use mass formulas / Siegel–Weil on the χ = −1 genus 𝔊⁻_p, restricted to lattices containing a fixed small binary
M = M_{v,t} = [[v, −1], [−1, t]] (det A* = tv − 1, gcd(A*, p) = 1). A path word (t, u, v) is exactly such a lattice with a
particular completion. If Siegel–Weil forces some L ∈ 𝔊⁻_p ⊃ M, is L a path lattice?

## Literature
Siegel's mass formula / Siegel–Weil for representations of binary by ternary lattices (Siegel 1935; Kitaoka, *Arithmetic of
quadratic forms*, Ch. 6); THREE_SQUARES §4 (α₂ and α_p vanish together on χ = −1: no weighting beyond the indicator);
redteam-automorphic-2 Thm 2.2 / Prop 10.3 (genus shadow versus exact residue).

## Result (PROVED, elementary gluing)
Let L have det p and contain M primitively. At ℓ | A* the lattice L is unimodular, so the projection of L onto M ⊗ ℚ is M^#
and M^⊥ = ℤz with |z|² = pA*. Fix the sign of z. Then L contains a unique class y ≡ −c·e₂^# + z/A* (mod M ⊕ ℤz) for some
c mod A*, which defines the glue c (M^#/M is cyclic, generated by e₂^#; self-review repair: c is defined through the fixed
complement projection z/A*, not through an arbitrary quotient generator). The norm condition is c²v ≡ −p (mod A*). Conversely
each such c gives
L_c = ⟨e₁, e₂, y⟩, Gram [[v, −1, 0], [−1, t, −c], [0, −c, (c²v + p)/A*]], det p.
All L_c have the same local invariants, hence the same genus and the same χ. **The fixed ordered basis (e₁, e₂) of M extends
to a path basis (e₁, e₂, e₃) of L_c (e₁·e₃ = 0, e₂·e₃ = −1) iff c ≡ ±1 (mod A*).** Such a completion exists iff ±1 is a root, i.e.
iff A* | p + v, and then it is the path lattice of the word (t, (p + v)/A*, v). (Self-review repair: the first version said
"L_c is a path lattice iff c ≡ ±1". That is false unmarked: p = 11, v = t = 4, A* = 15, c = 4 gives
G = [[4,−1,0],[−1,4,−4],[0,−4,5]], which is the path Gram of (4, 1, 4) in the basis (e₂, e₁, e₂ + e₃). It also claimed a root count
2^{ω(A*)−1} − 1, which fails at 2-power moduli, e.g. A* = 8, v = 1, p = 7 has roots 1, 3, 5, 7.) The remaining roots give
completions of the same M that do not extend this basis. So a Siegel–Weil/mass argument decides only whether −p·v⁻¹ is a square mod A* (a genus
condition). The word needs −p·v⁻¹ ≡ 1, a residue condition: B2 in gluing language (Prop 10.3: form-class tools see the
genus shadow).

## Barrier screen
B2/Prop 10.3: exactly the genus-versus-residue gap. B3: summing over (v, t) puts the main term at the level of the
number of words (log²p). T1: at squares no L_c is in a χ = −1 genus. Thm 9.1: no fixed-level identity.

## Cheap numerics
`scripts/z1_glue.py 100 400 30` (primes 100 < p < 400, A* ≤ 30): 2589 pairs (v, t) with a square root; 4172 non-path glues
c ≢ ±1, of which 732 (17.5 %) happen to be isometric to *some* path lattice of p through another marking; χ identical on all
glues of one M (0 mismatches).

## Assessment
PROVED negative dictionary. Siegel weights on 𝔊⁻_p cannot force a path class, because "contains M with the right genus"
is a square-root-class condition and the path needs the trivial class. The 17.5 % accidental coincidences are lattices with
several short-vector markings, with no structure. Promise 0/5.
