# z22_primorial_windows — K divisible by all primes ≤ y: what a (log p)^{O(1)} cap would need (O250; CAP_BOUNDED §4)

**Idea (brief).** Make K_q smooth / divisible by P(y) so that many small generators give small-exponent
representations of the forced −1 (Erdős–Rényi / Cauchy–Davenport / sum-product).
**Screen.** (1) Fixed generator set ⇒ good q divide a + b for finitely many box pairs a/b ⇒ congruence covering ⇒ T1
at p ≡ 1 (mod 4P(y)) (CAP_BOUNDED Z22-1, Thm 1.3). (2) Moving windows with K ≡ 0 (mod P(y)): box (C+3)^{π(y)} vs
q ≍ e^{O(y)} needs C ≳ y^{O(1)} = (log q)^{O(1)}; the deterministic covering step (Lemma 4.1) needs Diophantine-generic
discrete logs of the primes ≤ y mod q − 1 — not a Frobenius statement, so not GRH-accessible
(cf. z12_grh_lattice_gap). Cauchy–Davenport gives only a factor ω(K) over the one-prime witness.
**Label.** Assessment; Lemma 4.1 PROVED (standard). Missing input stated precisely.
