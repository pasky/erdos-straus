# y3_frob_infinity — semi-primitivity = "h imitates the infinite place"; why the bridge is archimedean (O211)

**ES is not solved here.** Labels as in DISCOVERIES.md.

## Idea
h ≡ −1 (mod m) ⟺ Frob_h = complex conjugation c_∞ in Gal(ℚ(ζ_m)/ℚ) ≅ (ℤ/m)^*, i.e. **h has the same decomposition
group as the archimedean place** of ℚ(ζ_m) (generated by c_∞, order 2). FF_MUTE ((J)30) works because a *finite* mute
place has Frobenius in the same group as P. Over ℚ, the place whose decomposition group is {±1} is ∞, whose residue
field is ℝ — and ES needs a finite place h imitating it.

## Dictionary (PROVED, elementary)
Let M = p + 4c²d, m = 4cd, σ_a ∈ Gal(ℚ(ζ_m)/ℚ) the class of a. Since M ≡ p (mod m), ∏_{q^e ∥ M} σ_q^e = σ_p (the
Artin symbol of the ideal (M)). Type II on slice (c, d) ⟺ **some sub-product of the prime factors of M has Artin
symbol c_∞** (h = that sub-product; prime-modulus Type II: a single prime factor with σ_q = c_∞). Thus:
* (h+1)-world = primes imitating ∞ (decomposition group = {1, c_∞}); (h−1)-world = F_h^* where −p must equal a box
  value; TORSION_FIRING Thm 3.1's gcd = 2 is |D_∞| = 2.
* (checked: scripts/y3_span.py 10⁵, 87 405 slice instances with gcd(M, 4cd) = 1, of which 86 310 at primes, 0
  mismatches; odd squares: 0 firing slices. Hypothesis gcd(p, 4cd) = 1, automatic for primes p ≥ 5.)
* When (ℤ/m)^* is an elementary 2-group (m | 24, i.e. cd | 6), "−1 is a sub-product" ⟺ −1 ∈ F_2-span of the classes
  ⟺ **no odd quadratic character χ mod m has χ(q) = 1 for every q | M** ⟺ M is not composed solely of primes split in
  one imaginary quadratic field ℚ(√D), D | m, D < 0 (genus theory; folklore-level, cf. the zero-sum memos
  polynomial_method / wildcard W15, which treat general m and collapse to B1).
* Box (archimedean) side: given h ≡ −1, the residue −p ∈ {c/j : cj | (h+1)/4} is a statement about the integer
  sizes c, j (Prop G of y3_lucas_dickson_trace: algebraic bridges carry only rationals). So "imitating ∞" is
  precisely the point where sizes (the real place) enter.
