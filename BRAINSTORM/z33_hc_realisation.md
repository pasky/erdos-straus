# z33_hc_realisation — non-abelian data of p add nothing at bounded levels (O263; §6; CONDITIONAL)

**Idea.** Even if residue symbols do not see classes, maybe some Chebotarev class C of p (in a governing field) is
covered by bounded-level certificates for an arithmetic reason invisible to congruences.
**Literature.** Dickson / Schinzel H; Bateman–Horn; B1_LINE Thm 4.2 (Ω = ℚ, d-coordinate).
**Result (CONDITIONAL on HC = Dickson with one Chebotarev condition).** Thm 6.1: for every D, every finite Galois Ω and
every class C compatible with p ≡ 1 (mod M), infinitely many p ∈ C have NO certificate on the b = 1 line (either coordinate)
or on any Type I/II e-slice at levels ≤ D. Proof: p = 1 + Mk, every N_i = (smooth part of N_i(1))·prime; then Σ(N_i) is
the forced set of the integer at "p = 1", which misses −1 (Thm 3.4). Admissibility needs B ≥ 4D + 2.
**Barrier screen.** Extends B1_LINE Thm 4.2 to all four lines and to arbitrary governing data; silent on unbounded levels.
**Assessment.** The non-abelian hatch (H-D) is closed for bounded-level divisor certificates, conditionally.
