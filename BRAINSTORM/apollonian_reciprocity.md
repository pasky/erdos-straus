# BRAINSTORM — Apollonian reciprocity obstructions as an analogue for ES (O144, angle b)

Labels as in DISCOVERIES.md. ET = Elsholtz–Tao arXiv:1107.1010; BL = Bright–Loughran arXiv:1908.02526
(`sources/`); HKRS = Haag–Kertzer–Rickards–Stange, *The local-global conjecture for Apollonian circle
packings is false*, Ann. of Math. 200 (2024), arXiv:2307.02749 (v3 PDF read for this memo).

## 1. Idea

HKRS: in a primitive integral Apollonian packing 𝒜, the curvatures tangent to a circle C of curvature n
are the values `f_C(x,y) − n` (gcd(x,y)=1) of a form of discriminant −4n². Mod n the form degenerates,
so the Kronecker symbol `(n/c)` is constant over tangent curvatures c, which defines χ₂(C). Quadratic
reciprocity gives χ₂(C₁) = χ₂(C₂) for tangent coprime circles. Connectedness of the packing then makes
χ₂(𝒜) a packing invariant. If χ₂(𝒜) = −1, every family `S_{2,u} = {u·m²}` with the forced symbol is missing.
A finer χ₄ ∈ {±1, ±i}, built from Gaussian ideals, kills quartic families `{u·m⁴}`.

ES analogue: ET Prop 1.6 (odd squares have no Type I/II point) is a quadratic-reciprocity obstruction.
BL Cor 1.4 explains it by the Brauer class α. The question of the task:
**(Q1)** are there further (quartic/higher) reciprocity obstructions for Type I ∪ Type II?
**(Q2)** could one kill an infinite set of *primes*?
**(Q3)** does HKRS suggest a proof that no further obstructions exist?

## 2. Literature anchor (verified)

* HKRS Thm 1.3 / Def 2.2 / Thm 2.4, quoted from the arXiv v3 PDF. The obstructions are exactly the sets
  `S_{d,u} = {u·m^d}` with d = 2 (quadratic) or d = 4 (quartic). Abstract: they "are a property of the thin
  Apollonian group (and not its Zariski closure)". §1.4: the super-Apollonian group (between Apollonian and
  Zariski closure) has an orbit that contains all integers, so its Zariski closure carries no such obstruction.
* HKRS Conj 1.5: the "sporadic set" left after removing these families is finite. It is OPEN. The best proved
  result is Bourgain–Kontorovich (Invent. 2014): density one, with O(N^{1−η}) missing (HKRS Thm 1.2).
* BL (read in `sources/`): `Br U_n / Br ℚ ≅ ℤ/2`, generated by the transcendental α. Cor 2.7: over a field k,
  `Br Ũ_n / Br k` is indexed by roots of unity ζ ∈ μ(k), through `α_ζ = (−u₁/u₃, −u₂/u₃)_ζ`. Lemma 3.4:
  `inv_p α(u) = ((−u₂/u₃)/p)^{v_p(u₁u₃)}` when u₂/u₃ ∈ ℤ_p^*. Lemma 3.5: invariants are trivial at p ∤ 2n.
  Lemma 3.8: they are trivial at 2 for n odd. Lemma 3.1: `inv_∞ = −1` on positive points. The proof of
  Lemma 3.6 builds p-adic points with `p ‖ u₁`, `p ∤ u₂u₃` and either value of `((−u₂/u₃)/p)`.

## 3. Barrier screen and the theory answer

**Prop B.1 (PROVED relative to BL Lemmas 3.1, 3.4, 3.5, 3.8 and the local solubility in BL Thm 1.8; elementary).**
Let p ≥ 3 be prime. Restrict the p-adic component of BL's adelic space to the Type I shape
(exactly one coordinate divisible by p), or alternatively to the Type II shape (exactly two). In both cases the
Brauer–Manin set is non-empty. So no Brauer–Manin (= reciprocity) obstruction exists to Type I, or to Type II,
at any prime.
*Proof.* Use BL's real and ℓ-adic components (ℓ ≠ p). Their invariants sum to `−1` (Lemmas 3.1, 3.5, 3.8), so
we need a p-adic point of the required shape with `inv_p = −1`.
* Type I: BL's own construction in the proof of Lemma 3.6 is Type-I-shaped (`p ‖ u₁`, p ∤ u₂u₃) and realises
  `((−u₂/u₃)/p) = −1`.
* Type II: put `u₁ = ps`, `u₂ = pt` with s, t units, and `X = 1/s`, `Y = 1/t`. The equation gives
  `u₃ = p/(4 − X − Y)`, so u₃ is a unit iff `v_p(4 − X − Y) = 1`. Hensel lets us take `Y = 4 − X + p`.
  Lemma 3.4, applied after an S₃-permutation (α is S₃-invariant), gives
  `inv_p = ((−s/t)/p) = ((−Y/X)/p) ≡ ((1 − 4/X)/p)`.
  As X runs over units with X ≢ 4 (mod p), `1 − 4/X` takes every non-zero residue except 1, so it takes a
  non-residue. ∎

**Prop B.2 (PROVED, from BL Cor 2.7).** Over ℚ there is no Brauer class beyond α. A quartic analogue
`α_i` exists only over fields containing μ₄, e.g. ℚ(i). So *no quartic (or higher) Brauer–Manin obstruction
can exist for ES over ℚ*, for any n.

**Assessment (Q1/Q2).** HKRS's quartic obstruction is not Brauer–Manin on the Zariski closure. It comes from
constancy of χ₄ along an *infinite orbit of a thin group* (tangency moves). ES has no analogue of that orbit.
* For fixed n the integral points off the lines are finite (BL Lemma 3.10).
* The fixed-n equation `a(4bcd − 1) = b + nc` is linear in each variable, so there is no Vieta/Markoff-type
  involution group that could carry an invariant.

So an HKRS-type non-BM invariant has nothing to propagate along. Moreover, every HKRS-type family `{u·m^d}`,
d ≥ 2, contains at most one prime (namely when m = 1). An obstruction killing infinitely many primes would
therefore need a mechanism of a different nature from both HKRS and BL. If it existed it would be a "sterile
prime" family (the symmetry remark in redteam-automorphic-2 §3).

**B1–B6 / T-tests.** This angle produces no existence route, so B2/B3/B6 do not bind. T1 is the *source* of
the analogy. The HKRS positive side (density one, Bourgain–Kontorovich) is exactly a B6 average statement.
HKRS Conj 1.5 ("no further obstructions") is open even for packings. So (Q3): **no proof strategy is
imported**. The analogy only maps the open problem "sporadic set finite" ↔ "ES for all primes".

## 4. Experiments (`scripts/bs_farey_obstr.py`, data from `scripts/spec_typecount.c`, ET coordinates)

* **Odd n with no Type I/II point (ET coordinates), n ≤ 10⁶.** They are exactly the odd squares, plus the single
  sporadic n = 105. ⚠ 105 is an artefact of the coordinate definition for composite n. A direct count of
  "exactly one/two of x,y,z divisible by n" (scripts/review_r127_counts.c) gives f_I(105) = 252 and
  f_II(105) = 18; it also gives f_I(81) = 82, so the naive definition does not even see ET 1.6. No quadratic
  family `u·m²` with u ≠ 1, and no quartic family, appears among the odd zeros. Even n: many zeros (6, 12, 22, …),

## 5. Viability Assessment

**COLLAPSES (as an existence route) / PARTIAL (as a structural statement).**
* No higher reciprocity obstruction can exist for ES over ℚ in the Brauer–Manin sense (Prop B.2).
* The BM set of each of the Type I and Type II loci is non-empty at every prime (Prop B.1). The Type I part is
  implicit in BL's proof; the Type II part is a short extension.
* The HKRS non-BM mechanism needs an infinite group orbit, which ES at fixed n lacks.
* Data show no quartic bias.

By-products:
* Prop B.1 (PROVED relative to BL; novelty low).
* Prop B.2 (PROVED; a reading of BL Cor 2.7).
* The census "odd Type I/II zeros ≤ 10⁶ = odd squares ∪ {105}" (EVIDENCE; 105 is a coordinate artefact).
