# bsB_orthant_sign — the ES sign is the real orthant of one cubic, transported to the place n (O175)

**ES is not solved here.** Labels as in DISCOVERIES.md.

## Idea
GI Prop 4.1 splits a sign-blind set D*(n) into class +1 / class −1. Identify both classes as integral points of
the *same* variety, so that the sign becomes an archimedean datum, and ask what the "sign layer" then is in
Hilbert-reciprocity terms; look for a map from the always-populated class to the ES class.

## Dictionary (PROVED, elementary)
Let n ≡ 1 (4) and X_n : `cfg − c − f = n`, with the 2-adic condition fg ≡ 1 (mod 4) and g ≥ 1.
1. gn + 1 = (cg − 1)(fg − 1), so the points of X_n with c, f ≥ 1 are the Type I (a = 1) certificates
   (class −1 of D*(n), m'' = cg − 1), and the points with **c, f ≤ −1** are exactly the class +1 elements of
   D*(n) (m'' = |c|g + 1, m = |f|g + 1; the substitution (c, f) ↦ (−c, −f) turns X_n into `cfg + c + f = n`). (Mixed-sign orthants are not
   part of D*(n) and are not used.)
2. **Sign = orthant**: `((cg − 1)/n) = −sgn(c)` on X_n(ℤ) ∩ {cf > 0} (GI Prop 4.1 restated). So the genus
   character at the place n equals the archimedean "orthant character" — Hilbert reciprocity with the two
   relevant places ∞ and n (the 2-adic place is fixed by fg ≡ 1 (4); the places dividing g contribute (−1/g)·…,
   as in the GI proof).
3. **T1 = no positive points at squares**: at n = k² the place-n character is trivial, so only the negative
   orthant is populated. **SQ (slice form)**: the positive orthant of X_n(ℤ) is empty only at squares and the 26
   composites listed in `bsB_theta_multiplier.md` (EVIDENCE ≤ 2·10⁶).
Checked (`scripts/bsB_orthant.py 300`): n ≡ 1 (4) ≤ 300: 237 positive-orthant and 454 negative-orthant points;
orthant counts equal the D*(n) class counts and the symbol formula holds, 0 violations.

## Construction attempts (barrier as steering wheel)
* *Orthant-crossing maps.* X_n is linear in each variable, so it has no Vieta involutions; its integral
  automorphisms fixing the 2-adic condition are generated by (c, f) ↔ (f, c) — orthant-preserving. A rational
  map defined uniformly in n that sends negative points to positive points would do so at n = k² as well,
  contradicting T1. *Modification:* make the map depend on an auxiliary non-residue ℓ (χ_n(ℓ) = −1). Any
  sign-multiplicative composition (form composition, Bhargava cubes, DE's Jacobi forcing) maps class
  (+1)·(−1-twist) to class −1 only at the **group level** (DE Prop 6.2, Thm 7.3: block witnesses miss a congruence
  class) — the twist produces an element with the right sign but not a divisor of the right integer (B2).
* *Real-region counting.* "Integral points of a log-K3-type cubic in a cone" is a counting problem: B3 (main term
  ≍ log²n, polylog lottery) and B5 (the cone count is local, identical at squares, except for the one bit).
* *BM.* Item 2 is the Bright–Loughran Brauer class ((I)7) evaluated on the two orthants: BM with the real place
  sees exactly one bit.
