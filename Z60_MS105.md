## 3. Kernel lemmas (PROVED)

**Claim 0 (standard).** If t ≥ 1 and d ≡ −1 (mod 4t), d > 0, then (t/d) = 1 (Jacobi).
*Proof.* t = 2^a c, c odd. If a ≥ 1, 8 | 4t, d ≡ 7 (8), (2/d) = 1. Reciprocity with d ≡ 3 (4):
(c/d) = (d/c)(−1)^{(c−1)/2} = (−1/c)(−1)^{(c−1)/2} = 1. ∎

**Lemma 1 (twisted T1 on uC).** Let (u, B, C) solve R(n) and n = s·m² (s, m ≥ 1). Then s ∤ uC and s ∤ BC.
*Proof.* d := 4uC − 1 satisfies B·d = n + u, so n ≡ −u (mod d); gcd(d, n) = 1 (Z59_MSPLUS Lemma 2.0), so gcd(d, m) = 1.
(n/d) = (−u/d) = −(u/d) = −1 by Claim 0, and (n/d) = (s/d). If s | uC then d ≡ −1 (mod 4s) and (s/d) = 1 by Claim 0 —
contradiction. Swap u ↔ B for BC. ∎ (s = 1 is T1. Elementary corollary of the χ_n(d) = −1 fact, Z59_MSPF Lemma 1.5;
Claim 0 is the reciprocity computation of Z59_MSPF Lemma 1.3 / Z57_BFII Lemma 2.1; the same kernel-sign contradiction is
used in Z58_WILDCARD Lemma 4.3 for numerator K. Lemma 1 is a repackaging, recorded for the kernel bookkeeping.)
More precisely, with g = gcd(s, uC): ((s/g)/d) = −1 — the part of the kernel *not* absorbed by uC must be a Jacobi
non-residue of the witness.

**Lemma 2 (kernel decomposition).** (u, B, C) ↦ (g; u/g, B/g, gC), g = gcd(u, B), is a bijection
Sol(n) → ⊔_{g | n} {(u′, B′, C′) ∈ Sol(n/g) : gcd(u′, B′) = 1, g | C′}. Hence R(n) = Σ_{g|n} R*_g(n/g).
(g | n because n ≡ 0 mod g; inverse (u′, B′, C′) ↦ (gu′, gB′, C′/g). This is Z59_MSPLUS Lemma 5.1 summed over g.) For
n = s·m² the terms with s | g vanish (Lemma 1). For R₈ the same holds for odd n (all g odd); for even g one needs 2g | C′.

Both CERTIFIED by brute force for all n ≤ 6000 (`scripts/z60_ms105_lemma1_check.py 6000`: 78 200 (solution, s) pairs,
0 violations; decomposition exact for every n).

## 4. Polynomial families: a dichotomy (PROVED relative to standard theorems)

**Theorem 3.** Let f ∈ ℤ[t] be non-constant with positive leading coefficient.
* (a) If f = g² with g ∈ ℚ[t], then R(f(t)) = 0 for every t with g(t) an odd integer (T1).
* (b) Otherwise Z_f := {t ∈ ℕ : R(f(t)) = 0} has natural density 0.

So along a univariate polynomial family the zero set of R is everything (odd squares) or density zero: **no non-square
polynomial family carries a positive-density "twisted T1".** Generalises Z59_MSPLUS Lemma 4.1 (f = s·t²).

*Inputs, verified from the source* (Serre, *Topics in Galois Theory*, 1992, PDF of the Harvard notes): (HIT) Prop. 3.3.1 —
for a Galois covering W → V with group G there is a thin set A ⊂ V(ℚ) outside which the fibre is inert, i.e. a field
Galois over ℚ with group G; Prop. 3.3.5 is the polynomial form. (Cohen) Thm 3.4.4 (S. D. Cohen): a thin set of 𝔸ⁿ(ℚ) has
O(N^{n−1/2} log N) integral points of height ≤ N; for n = 1, O(N^{1/2} log N). Chebotarev's density theorem.

*Proof of (b).*
1. *Generic field.* f(t) + u is irreducible in ℚ(u)[t] (degree 1 in u, content 1; Gauss). For a root α,
   K := ℚ(u)(α) = ℚ(α) (u = −f(α)) is a rational function field with constant field ℚ. So i ∉ K, and √(−u) = √(f(α)) ∈ K
   iff f is a square in ℚ(t), i.e. f = g², g ∈ ℚ[t] — excluded. **This is the only use of non-squareness.**
2. *Specialise.* Let M be the Galois closure of K(i, √−u)/ℚ(u). By HIT there is a thin A ⊂ ℤ such that for q ∉ A the
   specialisation M_q is a field with Gal(M_q/ℚ) ≅ Gal(M/ℚ(u)), the stabiliser of a root α_q (f(α_q) = −q) corresponding
   to a conjugate of Gal(M/K). Since ℚ(u, i) and ℚ(u, √−u) are Galois over ℚ(u), their non-inclusion in K is a statement
   about normal subgroups and survives: i ∉ K_q, √−q ∉ K_q, K_q := ℚ(α_q). By Cohen, A has O(N^{1/2} log N) elements
   ≤ N, so some prime q ≡ 3 (mod 4) is not in A. Fix it.
3. *The cyclotomic part is real.* F := K_q ∩ ℚ(ζ_{4q}). Gal(ℚ(ζ_{4q})/ℚ) ≅ ℤ/2 × ℤ/(q−1) has elementary abelian 2-Sylow
   ((q−1)/2 odd), hence so does its quotient Gal(F/ℚ). If complex conjugation acted non-trivially on F, its image c̄ would
   have order 2 and could not be a square (squares have trivial 2-part); a character χ: Gal(F/ℚ) → {±1} with χ(c̄) = −1
   would cut out an imaginary quadratic subfield of ℚ(ζ_{4q}), i.e. ℚ(i) or ℚ(√−q), inside K_q — excluded by step 2. So
   F is real.
4. *Chebotarev.* N := Galois closure of K_q(ζ_{4q}). Restriction Gal(N/K_q) → Gal(ℚ(ζ_{4q})/ℚ) has image
   Gal(ℚ(ζ_{4q})/F), which contains complex conjugation c. Pick σ ∈ Gal(N/K_q) restricting to c. The primes ℓ (unramified
   in N, ℓ ∤ lc(f)·disc(f + q)) with Frob_ℓ conjugate to σ have positive density; for them ℓ ≡ −1 (mod 4q) and Frob_ℓ fixes
   a root, so f(t) + q has a root t_ℓ mod ℓ. Call this set 𝒫; Σ_{ℓ∈𝒫} 1/ℓ = ∞.
5. *Witness.* For ℓ ∈ 𝒫, t ≡ t_ℓ (mod ℓ), f(t) + q ≥ ℓ: u = q, C = (ℓ + 1)/(4q), d = 4uC − 1 = ℓ, B = (f(t) + q)/ℓ ≥ 1 give
   4uBC − u − B = B·ℓ − q = f(t). So R(f(t)) ≥ 1.
6. *Sieve.* For fixed z, the t ≤ T with f(t) ≥ z avoiding t_ℓ (mod ℓ) for all ℓ ∈ 𝒫, ℓ ≤ z, number
   T·∏_{ℓ∈𝒫, ℓ≤z}(1 − 1/ℓ) + O_z(1) (CRT; the finitely many t with f(t) < z are O(1)). The product → 0 as z → ∞. ∎

*Remarks.* (i) The proof applies verbatim to t restricted to an arithmetic progression (a non-constant affine substitution
preserves (non-)squareness in ℚ[t]). A several-variable version is **not** claimed (the argument above uses that
ℚ(t)/ℚ(f) is finite, and multivariate f can be negative on positive-density regions).
(ii) An upper-bound sieve should give |Z_f ∩ [1, T]| ≪_f T(log T)^{−δ}, δ the density of 𝒫 (not checked; not claimed).
(iii) **Scope.** Density zero is not finiteness. A density-zero zero set along f is not excluded — that is the brief's
thin-family threat. Applied to f∘h, Theorem 3 says Z_f contains no polynomial subfamily t ↦ h(t) **with f∘h non-square**;
non-squareness is not preserved by composition (f = 4t + 1, h = t(t+1) gives (2t+1)², all zeros), so the honest reading
is: every polynomially parametrised infinite family of zeros consists of squares (internal review M1). (iv) The proof is blind to R vs R₈ (ℓ ≡ −1 mod 8q; exclude the four
imaginary quadratic subfields ℚ(i), ℚ(√−2), ℚ(√−q), ℚ(√−2q) of ℚ(ζ_{8q}); valid unless f or 2f is a square), so it cannot
be a step of an (MS) proof by itself; it is a statement about *where* zeros can live.

## 5. Composite-only proof routes (brief (2))

### 5.1 Multiplicative ascent by scaling = inheritance (PROVED + CERTIFIED counts)
By Lemma 2, the solutions of R(ab) obtainable from a factor by **simultaneous scaling** (u, B, C) ↦ (gu, gB, C/g) are
exactly the imprimitive ones (a solution of R(n/g) with g | C). For a < b the small factor never helps by scaling once
b > (a + 2)/4 (its solutions have C ≤ (a + u + B)/(4uB) < b). So a scaling-ascent proof must produce, in the factor b, a
solution with **a | C** — a divisibility condition on the modulus parameter of the same tied type as B2 (Assessment: no
easier). Other, non-scaling transports exist and are not classified here: e.g. a witness with u = C = 1 (n = 3B − 1)
transports to kn for every k ≡ 1 (mod 3) via B′ = (kn + 1)/3 ((1, 6, 1) for 17 gives the primitive (1, 210, 1) for 629);
this particular one is just the d = 3 hit (n ≡ 2 mod 3) (internal review M4).
*Data (CERTIFIED, `scripts/z60_ms105_prim.c 20000000`, `data/z60/ms105/prim_2e7.txt`):* among n ≤ 2·10⁷, n ≡ 1 (4),
gcd(n, 105) = 1, non-square: 635 169 primes (mean R = 41.12, 14 zeros) and 1 649 523 composites (mean R = 39.95, 23 zeros;
means corrected after internal review M3 found an outer-loop bound omitting solutions in the first version of the engine).
Imprimitive (inherited) solutions average 0.668 per composite (1.7 % of R); they are the *only* solutions for just 6
composites (8569, 20 689, 115 489, 174 841, 4 264 249, 10 865 569). Inheritance is a marginal mechanism (EVIDENCE).
Unconditional closure fails both ways (Z59_MSPLUS §5.1: 12 538 801 = 517·24 253; 4545).

### 5.2 Induction on the kernel (PROVED pieces, Assessment conclusion)
For n = s·m², Lemma 1 forbids s | uC, s | BC; Lemma 2 reduces imprimitive solutions to n/g. Inside a fixed kernel class,
for a prime witness d ∤ m the hit condition is m ≡ ±√(−r/s) (mod d) for some r | (d+1)/4, possible only if (s/d) = −1 —
a sieve on m with exactly 2τ((d+1)/4) removed classes at the primes d ≡ 3 (4) with (s/d) = −1 (relative density 1/2).
Theorem 3 / Lemma 4.1 give density zero; finiteness is beyond the sieve methods available here (Assessment: the prime-d
sieve on m does not reach the scale of the needed moduli; no impossibility theorem is claimed). The
descent n ↦ n/q² has no inheritance in either direction (Z59_MSPLUS §4). Assessment: no induction on the kernel
transfers positivity from s (or from s·m′², m′ | m) to s·m².

### 5.3 CRT gluing: hits are anti-multiplicative (PROVED) + Assessment
**Proposition 4.** Let d ≡ 3 (4) and let a, b be integers coprime to d. If a and b are both d-form hits at d (a ≡ −r₁,
b ≡ −r₂ mod d with rᵢ | (d+1)/4), then ab is not a hit at d. More generally, ab is a hit at d only if
(a/d)(b/d) = −1.
*Proof.* A hit n ≡ −r (mod d), r | (d+1)/4, has (n/d) = (−1/d)(r/d) = −1 (Claim 0 with t = r). Hence
(ab/d) = (a/d)(b/d) = (−1)(−1) = 1 for two hits. ∎
So witnesses of a product live only at moduli where the factors have *opposite* Jacobi symbols (necessary, not
sufficient: d = 7, a = 29, b = 17 have opposite symbols but 493 is not a hit); gluing witnesses of
the factors at a common modulus is impossible, and a witness for ab is the event "ab ∈ H_d" for one d — the same
single tied event, not a statement about the factors (Assessment). For a = b this is T1 again. Prop. 4 is an immediate
corollary of the hit-class sign fact (Z59_MSPF Lemma 1.5; Z57_BFII Lemma 2.1); recorded as the gluing obstruction, not
as a new mechanism.
4Cab + 1 has no multiplicative relation to a, b; the M-form (modulus 4uB) behaves the same way (its classes contain no
square).

### 5.4 Minimal counterexample
The zero set is the complement of ⋃_{u,B} A_{u,B}, A_{u,B} = {n ≥ 4uB − u − B : n ≡ −(u+B) (mod 4uB)} (upward-closed
progressions; each A_{u,B} contains no square). A least non-square zero above the threshold admits no known descent: the
equation is linear in each variable (no Vieta move at fixed n), and scaling/inheritance maps go upward only (§5.1).

## 6. Brief (3): which strengthening of non-squareness do the data suggest?

* **None is needed on the evidence.** (MS⁺₁₀₅) survived every square-mimicking stress test above (no witness-free input above the threshold) (≈ 8.3·10¹⁰ structured
  input occurrences; kernel ≤ 10⁵ to 2⁶⁴; pseudosquares of depth up to 379; locally-square inputs mod P₈₃). Its zeros ≤ 10¹⁰ have Jacobi
  depth 5–37 (vs ≈ 50 % depth 3 for random n; depth 3 means n ≡ 2 (3) and d = 3 hits), i.e. they are mild pseudo-squares
  at small n — the depth effect is the zero law's covariate (Z59_MSPLUS model B), not a rigid obstruction.
* **A conditional implication (PROVED) and its reading (Assessment).** Every hit d has (n/d) = −1, so
  d_min(n) ≥ depth(n). Hence a proof of (MS⁺₁₀₅) that also gives witnesses d ≤ (log n)^A would bound the depth of every
  non-square n ≡ 1 (4) coprime to 105 by (log n)^A, i.e. give pseudosquare lower bounds of the shape log L_k ≥ p_k^{1/A}
  (GRH gives depth ≪ log² n; unconditional bounds are far weaker). Reading: positivity proofs need not come with such a
  witness bound, but any that does carries least-non-residue strength — as for primes (Z58_WITNESS). Data point: the last
  tabulated pseudosquare A002189(73) ≈ 4.2·10²⁴ has first hit 431 ≥ depth 379.
* **If a strengthening were wanted for provability**, the natural one is quantitative non-squareness, e.g. "depth(n) ≤ D"
  (n is a non-residue mod some prime ≤ D). This makes the witness problem *start* at a fixed prime ℓ ≤ D with
  (n/ℓ) = −1 but leaves the tied divisibility r | (d+1)/4 untouched (B2). No data-driven reason to prefer it.
* Variants allowing 3 | n etc. are worse (dead moduli; zeros continue past 10¹⁰, Z59_MSPLUS §3.4).
